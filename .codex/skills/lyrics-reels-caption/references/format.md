# 캡션 골격

빈 줄과 이모지, 전각 공백(　) 들여쓰기까지 그대로 따른다. 전체 2,200자 이내(목표 2,000자 이내), 해시태그 30개 이내. 완성 예시 두 편은 각각 약 1,300자.

```
{아티스트}「{곡명}」 가사로 배우는 일본어

{1문단: 기록·성과 + 곡 한 줄 소개. "…의 대표곡 '{곡명}'." 형태로 끝내도 됨}
{2문단: 타이업·제작 배경·사운드·보컬. 본인 발언은 인용 주체 명시}
{3문단: 해석 여지 + "개인적으로는 …" 감상 + 직접 해석 권유}

📖 가사 속 표현

・{제목 단어}({읽기}) {뜻}. {짧은 부연}. {관련 어휘}

「{가사 줄}」 {한국어 번역}
　・{단어}({읽기}) {뜻}
　・{문법} {설명}

(위 블록을 4~5회 반복)

🎧 곡: {곡명} / {아티스트} ({발매년})
📺 드라마: {타이업 작품} 주제가 ({방송사}, {년})   ← 타이업 있을 때만. 애니는 📺, 영화는 🎬, 게임은 🎮
💿 앨범: {앨범명} ({년})

가사로 일본어 공부하는 앱 Kotonoha, 프로필 링크에서 확인

#{곡명 원어} #{아티스트 원어} #{곡명 한글} #{아티스트 한글} #일본어공부 #{장르}일본어
```

- 보카로 곡이면 `🎧 곡: {곡명} / {P명} feat. {보컬} ({년})`, 해시태그 마지막은 `#보카로일본어`. J-POP 은 `#JPOP일본어`.
- JLPT 급수는 표기하지 않는다.
