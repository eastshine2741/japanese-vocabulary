# landing-web 디자인 방향

출처: 다크 커버 + 크림 본문 색 조합과 앱 `app-rn/src/theme/theme.ts`. 사용자가 따로 정한 방향이 생기면 이 파일을 고친다.

Reading this as: J-POP·애니 노래를 좋아하는 한국인 일본어 입문자를 위한 모바일 앱 소개 랜딩, 다크 커버 + 크림 본문 언어.
Dial: ENERGY 2 / RHYTHM 2 / MOTION 2

## 색

- 코어: 잉크 `#111418`(다크 커버), 크림 `#f5f4ef`(본문 바탕), 흰색.
- 강조 하나: 초록. 바탕·장식에는 `#52b98a`, 흰 바탕 위 글자와 버튼에는 대비 때문에 `#0b7a43`.
- 의미 색(품사·평가 버튼·연속 학습 주황·이해도 금색)은 앱 `theme.ts` 값을 그대로 가져온다. 앱 화면을 보여 주는 목업 안에서만 쓴다.
- 글로우는 히어로 폰 그림자 한 곳만. 페이지의 초점이 그 폰이라서.

## 글꼴

- Pretendard: 한국어 본문 가독성. 앱 제목 서체 Funnel Sans 에는 한글 글리프가 없다.
- Noto Sans JP: 가나·한자 글리프.
- Noto Serif JP: 히어로 배경 `言の葉` 한 곳. 앱 이름의 뜻을 보여 주는 장식.

## 구성과 움직임

- 기능은 카드로 쪼개지 않고 가사 한 줄 해부도 한 장면에 모은다. 앱의 핵심이 "가사 한 줄"이라서.
- 3단계(검색 → 분석 → 학습)는 앱의 실제 흐름이라 3단계로 둔다.
- 목업과 문구는 지금 앱 코드를 따른다.
- 움직이는 것: 히어로 가사 재생(제품 시연), 망각 곡선 그리기, 성명 문장 스크롤 연출, 학습 달력 채우기. 끝없이 도는 장식 루프는 두지 않는다.
- 섹션 머리 라벨(eyebrow)은 정보가 있는 히어로와 복습(간격 반복) 두 곳만.
- 화면 속 곡·가사는 창작 예시, 노래방 번호처럼 실제처럼 보이는 식별자는 넣지 않는다.
