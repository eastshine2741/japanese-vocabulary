# Product Intent: Home Study Opportunity Stack

## 사용자 목표

- 사용자는 홈탭에 진입하자마자 단어 하나를 복습하거나 배운다.
- 사용자는 복습 streak을 유지하기 위해 별도 메뉴를 찾지 않고 바로 오늘의 단어를 처리한다.
- 사용자는 복습을 마친 뒤, 추천곡·새 곡 검색 중 다음 학습 재료를 자연스럽게 고른다.

## 현재 문제

- 현재 홈은 Spotlight, 복습 현황, 추천곡, 최근 들은 곡, 단어장 현황이 섹션 단위로 나열된 dashboard에 가깝다.
- 사용자는 홈에서 먼저 "무엇을 할지" 선택해야 하며, 앱 진입 즉시 학습이 시작되는 느낌이 약하다.
- 복습할 단어와 아직 담지 않은 곡이 같은 홈 안에 섞여 있지만, 각각이 `내가 지금 처리할 학습`, `새로 시작할 학습 재료`, `내가 가진 학습 자산` 중 무엇인지 즉시 구분하기 어렵다.

## 제품 방향

홈탭을 `기능 진입점 모음`이 아니라 `학습 카드 stack`으로 정의한다.

- 홈의 기본 단위는 곡, 단어장, 섹션이 아니라 `카드`다.
- 앱 진입 시 첫 화면에는 항상 카드 한 장이 보인다.
- 홈은 단어장을 고르는 화면이 아니라, 시스템이 고른 곡/단어장의 단어 카드로 시작한다.
- 시스템은 가장 due 단어가 많이 남아있는 곡/단어장을 고른다.
- 한 곡/단어장의 due 단어를 모두 끝내면, `복습 완료 카드`가 다음으로 due 단어가 많은 곡을 넛지한다.
- 복습할 단어가 없거나 복습을 모두 끝내면, `복습 완료 카드`가 추천곡 학습 또는 새 곡 검색을 제안한다.
- '복습 완료 카드'에서 추천곡 학습을 선택하면 즉시 단어장을 생성한 뒤 그 단어들을 보여주도록 이어진다.

와이어프레임 기준: `app-rn/japanese-vocabulary.pen`의 `WF - Home study opportunity stack v6 due nudge` 보드.

## 성공 기준

- 사용자는 홈 진입 직후 별도 선택 없이 단어 하나를 볼 수 있다.
- 사용자는 현재 곡/단어장의 due 복습을 마친 뒤 `복습 완료 카드`에서 다음 행동을 고를 수 있다.
- 사용자가 다음 행동을 고르면, '다음 due 곡'과 '추천곡'은 단어장을 생성한 뒤 단어 카드로 이어지고 새 곡 검색은 검색탭으로 이동한다.
- 홈의 주요 UI는 모두 카드 단위로 표현되며, 섹션형 dashboard로 돌아가지 않는다.

## Scope

- 홈탭의 정보구조와 주요 인터랙션 모델 변경
- 홈 진입 시 표시할 첫 카드 결정 규칙
- 홈에 임베드되는 복습 카드 UX
- due 복습 완료 후 다음 학습 카드 선택 UX
- 복습 완료 카드에서 추천곡 단어장 생성과 새 곡 검색을 제안하는 UX
- 홈탭에서 streak을 단어 카드의 동기 장치로 노출하는 방식
- 홈탭에서 사용할 카드 타입, 우선순위, 전환 규칙 정의
- 홈탭에서 시스템이 현재 이어서 볼 곡/단어장을 고르는 규칙
- 한 곡/단어장 복습 완료 후 다음 due-heavy 곡을 넛지하는 UX

- 추천곡 선정·정렬 알고리즘 변경
- 최근 분석된 곡의 랭킹·개인화 알고리즘 고도화
- 방금 열린 곡 또는 최근 유저들이 분석한 곡 노출
- 방금 열린 곡을 위한 API, 데이터 모델, 랭킹, 캐시, privacy 정책
- 홈 상단에 모든 단어장을 가로 탭으로 나열하는 UI
- 홈 상단에 단어장 드롭다운, 학습 범위 선택기, 단어장 picker를 두는 UI

## 핵심 원칙

### One Word First

홈의 첫 가치는 `단어 하나를 복습하거나 배운다`다.

첫 화면은 검색창, 추천곡 목록, 단어장 현황이 아니라 현재 처리할 카드여야 한다. 복습할 단어가 있으면 due 단어를 `단어 카드`로 보여주고, due가 없으면 `복습 완료 카드`에서 다음 행동을 고르게 한다.

### Card, Not Section

홈에서 만나는 주요 UI는 모두 카드다.

복습 완료 상태도 별도 섹션이 아니라 stack 안의 카드로 표현한다. 홈은 긴 dashboard 문서가 아니라 한 장씩 넘기는 카드 stack이다.

### Continue, Then Nudge

홈은 사용자가 단어장을 고르는 곳이 아니라, 시스템이 `지금 이어서 볼 곡`을 골라 단어 카드로 시작하는 곳이다.

```text
Lemon에서 이어 보기
오늘 다시 볼 단어 3개
```

단어장이 많아질수록 홈에서 필요한 것은 탐색 UI가 아니라 좋은 기본값이다. 유저는 단어장 목록을 관리하지 않고도 단어 하나를 바로 처리해야 한다.

현재 이어서 볼 곡/단어장 결정 규칙:

- 직전에 홈에서 보던 곡/단어장에 due 단어가 남아 있으면 그 곡을 이어서 보여준다.
- 직전 곡/단어장에 due가 없으면 due 단어가 가장 많은 곡/단어장을 보여준다.
- due가 전혀 없으면 `복습 완료 카드`를 보여준다.
- 추천곡 단어장을 새로 생성하면 그 곡이 즉시 `지금 이어서 볼 곡`이 된다.

한 곡/단어장의 due 단어를 모두 끝내면, 완료 카드는 다음으로 due 단어가 많은 곡을 넛지한다.

```text
Lemon 단어를 다 봤어요

다음 복습
夜に駆ける · 오늘 다시 볼 단어 6개

[이어서 복습]
[추천곡의 단어 학습]
[새 곡 검색]
```

이 방식은 곡 단위 맥락을 유지하지만, 유저에게 `큐`, `필터`, `단어장 선택` 같은 관리 개념을 요구하지 않는다.

### Recommendation Creates Word Cards

추천곡은 별도 카드 타입이 아니다. `복습 완료 카드`의 action으로만 노출하고, 사용자가 `추천곡의 단어 학습`을 탭하면 그 순간 추천곡의 단어장을 생성한다. 생성이 끝나면 해당 단어장의 단어들을 기존 `단어 카드` 타입으로 표시한다.

나쁜 방향:

```text
추천곡 카드
Lemon · 米津玄師
```

좋은 방향:

```text
복습 완료 카드
[추천곡의 단어 학습]

탭하면 추천곡 단어장 생성

단어 카드
Lemon · 米津玄師
夢 · ゆめ · 꿈
```

`새 곡 검색`은 홈 카드 타입이 아니다. `복습 완료 카드`의 action으로만 노출하고, 탭하면 홈 stack에는 변화 없이 검색탭으로 이동한다.

## 홈 카드 타입

홈탭의 카드 타입은 두 가지뿐이다.

1. `단어 카드`
2. `복습 완료 카드`

추천곡에서 온 단어든, 기존 due 복습 단어든, 사용자가 새로 만든 단어장에 들어간 단어든 모두 `단어 카드`다. source와 생성 경로는 다를 수 있지만 카드 타입은 늘 같다.

다음으로 due 단어가 많은 곡을 제안하는 UI도 별도 카드 타입이 아니다. `복습 완료 카드` 안의 추천 action으로 표현한다.

### 단어 카드

단어를 복습하거나 새로 배우는 카드다.

- 단어, 읽기, 가사 예문, 곡 출처를 보여준다.
- 곡 단위 맥락을 유지하기 위해 카드 바깥 상단 영역에 곡명, 아티스트명, 앨범커버를 출처로서 노출한다. 클릭하면 SongDetailScreen으로 이동
- front 상태에서는 headword만 보여주고 뜻 등을 숨기고 `뜻 보기`를 primary action으로 둔다.
- back 상태에서는 뜻, 발음, 예문 등 나머지와 FSRS 평가 버튼을 보여준다.
- rating 선택 후 위로 스와이프하면 다음 단어 카드로 이어진다.
- streak은 카드 밖 별도 영역에 표시한다.

### 복습 완료 카드

현재 곡/단어장의 due 단어를 모두 끝냈거나, 전체 due가 없을 때 표시한다.

권장 문구:

```text
Lemon의 모든 단어를 복습했어요
모든 단어를 복습했어요
```

첫 문구는 특정 곡/단어장을 끝냈을 때 사용한다. 두 번째 문구는 전체 due가 전혀 없을 때 사용한다.

역할:

- 복습 완료를 알려준다.
- 다음으로 due 단어가 많은 곡/단어장을 넛지한다.
- 사용자가 다음에 무엇을 볼지 고른다. 단, 수십·수백 개 단어장을 직접 고르게 하지 않는다.
- 선택지
  - `이어서 복습` -> 넛지된 곡/단어장의 단어 카드로 이어진다.
  - `{추천곡}의 단어 학습` -> 그 순간 추천곡의 단어장을 생성하고, 생성된 단어들로 다음 `단어 카드`들을 띄운다.
  - `새 곡 검색`을 탭하면 홈 stack 상태는 유지한 채 검색탭으로 이동한다.

## 카드 순서 규칙

```text
1. 단어 카드 · Lemon
2. 단어 카드 · Lemon
3. 단어 카드 · Lemon
...
N. 복습 완료 카드 · Lemon 완료 + 선택지들
```

## 인터랙션 모델

### 기본 제스처

- 단어 카드 front 탭 또는 `뜻 보기` 탭: 단어 카드 back 공개
- 단어 카드 back의 rating 탭: rating 선택
- rating이 선택된 단어 카드 back에서 위로 스와이프: 선택한 rating 저장 + 다음 카드 진행
- 복습 완료 카드의 action 탭: 해당 action 즉시 실행
- 복습 완료 카드의 `이어서 복습` 탭: 넛지된 다음 due-heavy 곡의 첫 단어 카드 표시

홈의 기본 이동은 세로 문서 스크롤이 아니라 카드 단위 전환이다. 카드 stack은 단방향 진행 모델이며, 이전 카드로 되돌아가는 제스처나 기능은 제공하지 않는다. 위로 스와이프는 단어 카드 back에서 rating이 명시 선택된 경우에만 다음 카드 진행으로 동작한다.

### FSRS 평가

단어 카드 back의 rating 선택지는 다음 4개다.

- `다시`
- `어려움`
- `알고 있음`
- `쉬움`

## 주요 플로우

### 복습 due가 있는 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 직전에 이어 보던 곡/단어장 또는 due 단어가 가장 많은 곡/단어장을 고른다.
3. 시스템은 해당 곡/단어장의 due 단어 중 하나를 `단어 카드`로 표시한다.
4. 사용자는 뜻을 떠올린 뒤 카드 또는 `뜻 보기`를 탭한다.
5. 시스템은 같은 카드에서 뜻과 FSRS rating을 표시한다.
6. 사용자가 rating을 탭해 선택한다.
7. 사용자가 위로 스와이프한다.
8. 시스템은 선택한 rating을 저장하고 같은 곡/단어장의 다음 단어 카드를 표시한다.
9. 해당 곡/단어장의 due 단어를 모두 끝내면 `복습 완료 카드`를 표시한다.
10. 완료 카드는 다음으로 due 단어가 많은 곡/단어장을 넛지한다.
11. 사용자가 `이어서 복습`을 탭하면 넛지된 곡/단어장의 첫 `단어 카드`를 표시한다.
12. 사용자가 `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 해당 단어장의 첫 `단어 카드`를 표시한다.
13. 사용자가 `새 곡 검색`을 탭하면 시스템은 홈 stack을 변경하지 않고 검색탭으로 이동한다.

### 현재 곡/단어장을 끝낸 유저

1. 사용자가 한 곡/단어장의 due 단어를 모두 처리한다.
2. 시스템은 `복습 완료 카드`를 표시한다.
3. 시스템은 아직 due 단어가 남은 곡/단어장 중 due count가 가장 큰 곡을 `다음 복습`으로 제안한다.
4. 사용자는 `이어서 복습`, `추천곡의 단어 학습`, `새 곡 검색`, `계속 복습` 중 하나를 탭한다.
5. `이어서 복습`을 탭하면 시스템은 넛지된 곡/단어장의 첫 `단어 카드`를 표시한다.
6. `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 해당 단어장의 첫 `단어 카드`를 표시한다.
7. `새 곡 검색`을 탭하면 시스템은 홈 stack을 변경하지 않고 검색탭으로 이동한다.

### due가 없고 저장 단어장이 있는 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 `스트릭 유지됨` 또는 오늘 완료 상태를 작은 문구로 보여준다.
3. 시스템은 `복습 완료 카드`를 표시한다.
4. 사용자는 `추천곡의 단어 학습`, `새 곡 검색`, `계속 복습` 중 하나를 탭한다.
5. `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 해당 단어장의 첫 `단어 카드`를 표시한다.
6. `새 곡 검색`을 탭하면 시스템은 홈 stack을 변경하지 않고 검색탭으로 이동한다.

### 완전 신규 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 `복습 완료 카드`를 표시한다.
3. 사용자는 `추천곡의 단어 학습` 또는 `새 곡 검색`을 선택한다.
4. `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 첫 `단어 카드`를 표시한다.
5. 사용자는 이 앱이 곡 가사에서 단어를 배우는 앱이라는 것을 첫 `단어 카드`에서 이해한다.

## 사이드케이스 플로우

### due 조회 실패

1. 홈 진입 시 due 조회가 실패한다.
2. 시스템은 홈 전체를 오류 화면으로 만들지 않는다.
3. 사용 가능한 추천곡이 있으면 `복습 완료 카드`를 통해 추천곡 단어장 생성 또는 새 곡 검색을 제안한다.
4. 복습 상태는 다음 포커스 또는 명시 재시도 때 다시 조회한다.

### 추천곡이 없음

1. 추천곡 API가 빈 목록을 반환한다.
2. 시스템은 `복습 완료 카드`에서 `추천곡의 단어 학습` 선택지를 숨긴다.
3. 사용자는 `새 곡 검색`을 통해 검색탭으로 이동할 수 있다.

### 단어 미리보기를 만들 수 없는 추천곡

1. 추천곡에 노출 가능한 단어/가사 예문이 없다.
2. 시스템은 해당 곡을 추천곡 단어장 생성 후보로 사용하지 않는다.
3. 다른 추천곡 후보가 없으면 `추천곡의 단어 학습` 선택지를 숨긴다.

## 데이터 요구사항

기존 데이터로 가능한 영역:

- flashcard due 카드
- FSRS rating
- streak/home stats
- 추천곡 목록
- 최근 들은 곡
- SongDetail 분석 결과가 있는 곡의 단어/가사 예문

추가 검토가 필요한 영역:

- 홈용 추천곡 단어장 생성 후보 API
- 홈 stack을 구성하는 서버 주도 feed API가 필요한지, 클라이언트 조합으로 충분한지
- 직전에 홈에서 보던 곡/단어장을 저장할 클라이언트 상태 또는 서버 상태
- 다음 due-heavy 곡 넛지에 필요한 곡명, 아티스트, 남은 due count 표시 데이터

## 결정 경계

제품 확인이 필요한 변경:

- due 복습 카드 사이에 discovery 카드를 자동 삽입하는 정책
- streak 유지 조건 변경
- SongDetail 진입/생성 완료 후 목적지 변경
- 홈을 SNS식 무한 피드로 확장하는 결정
- 홈 상단에 여러 단어장을 고정 탭으로 노출하는 결정
- 홈에 단어장 드롭다운, 학습 범위 선택기, 단어장 picker를 다시 도입하는 결정
