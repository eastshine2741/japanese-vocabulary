# Product Intent: Home Study Opportunity Stack

## 사용자 목표

- 사용자는 홈탭에 진입하자마자 단어 하나를 복습하거나 배운다.
- 사용자는 복습 streak을 유지하기 위해 별도 메뉴를 찾지 않고 바로 오늘의 단어를 처리한다.
- 사용자는 복습을 마친 뒤, 추천곡·새 곡 검색 중 다음 학습 재료를 자연스럽게 고른다.
- 사용자는 좋아하는 노래의 가사 의미가 궁금할 때, 그 곡을 단어장 생성 퍼널로 이어간다.

## 현재 문제

- 현재 홈은 Spotlight, 복습 현황, 추천곡, 최근 들은 곡, 단어장 현황이 섹션 단위로 나열된 dashboard에 가깝다.
- 사용자는 홈에서 먼저 "무엇을 할지" 선택해야 하며, 앱 진입 즉시 학습이 시작되는 느낌이 약하다.
- 복습할 단어와 아직 담지 않은 곡이 같은 홈 안에 섞여 있지만, 각각이 `내가 지금 처리할 학습`, `새로 시작할 학습 재료`, `내가 가진 학습 자산` 중 무엇인지 즉시 구분하기 어렵다.
- 검색·추천곡을 세로 스크롤 하단 섹션으로 두면, 홈의 주 경험인 복습 카드와 제스처 문법이 분리된다.
- 단어장 생성 퍼널이 약한 상태에서 추천곡을 단순 곡 카드로 보여주면, "이 곡으로 단어를 배운다"는 핵심 가치가 약해진다.

## 제품 방향

홈탭을 `기능 진입점 모음`이 아니라 `학습 기회 카드 stack`으로 정의한다.

- 홈의 기본 단위는 곡, 단어장, 섹션이 아니라 `학습 기회 카드`다.
- 앱 진입 시 첫 화면에는 항상 카드 한 장이 보인다.
- 복습할 단어가 있으면 복습 단어 카드가 최우선이다.
- 복습할 단어가 없거나 복습을 모두 끝내면, `복습 완료 카드`가 추천곡 단어장 생성 또는 새 곡 검색을 제안한다.
- 추천곡도 단순 앨범 카드로 노출하지 않는다. 추천곡 action은 단어장을 생성한 뒤 `곡에서 뽑은 단어 하나`를 `단어 카드`로 보여주는 방식으로 이어진다.

와이어프레임 기준: `app-rn/japanese-vocabulary.pen`의 `WF - Home study opportunity stack v4 updated` 보드.

## 성공 기준

- 사용자는 홈 진입 직후 별도 선택 없이 단어 하나를 볼 수 있다.
- 복습 due가 있으면 추천곡 단어장 생성이나 검색 진입 제안이 복습 카드 사이에 끼어들지 않는다.
- 사용자는 due 복습을 모두 마친 뒤 `모든 단어를 복습했어요` 카드에서 다음 행동을 고를 수 있다.
- 사용자가 다음 행동을 고르면, 추천곡은 단어장을 생성한 뒤 단어 카드로 이어지고 새 곡 검색은 검색탭으로 이동한다.
- 홈의 주요 UI는 모두 카드 단위로 표현되며, 섹션형 dashboard로 돌아가지 않는다.
- SongDetail을 변경하지 않고도 홈탭 안에서 복습 강화와 단어장 생성 퍼널 강화가 동시에 가능하다.

## Scope

- 홈탭의 정보구조와 주요 인터랙션 모델 변경
- 홈 진입 시 표시할 첫 카드 결정 규칙
- 홈에 임베드되는 미니 복습 카드 UX
- due 복습 완료 후 다음 학습 카드 선택 UX
- 복습 완료 카드에서 추천곡 단어장 생성과 새 곡 검색을 제안하는 UX
- 홈탭에서 streak을 단어 카드의 동기 장치로 노출하는 방식
- 홈탭에서 사용할 카드 타입, 우선순위, 전환 규칙 정의

- 추천곡 선정·정렬 알고리즘 변경
- 최근 분석된 곡의 랭킹·개인화 알고리즘 고도화
- 방금 열린 곡 또는 최근 유저들이 분석한 곡 노출
- 방금 열린 곡을 위한 API, 데이터 모델, 랭킹, 캐시, privacy 정책
- SNS식 무한 피드, 좋아요, 팔로우, 댓글, 공유 등 소셜 기능
- 음악 감상 앱으로서의 playback 중심 홈
- 홈 외 탭의 정보구조 변경

## 핵심 원칙

### One Word First

홈의 첫 가치는 `단어 하나를 복습하거나 배운다`다.

첫 화면은 검색창, 추천곡 목록, 단어장 현황이 아니라 현재 처리할 카드여야 한다. 복습할 단어가 있으면 due 단어를 `단어 카드`로 보여주고, due가 없으면 `복습 완료 카드`에서 다음 행동을 고르게 한다.

### Card, Not Section

홈에서 만나는 주요 UI는 모두 카드다.

복습 완료 상태도 별도 섹션이 아니라 stack 안의 카드로 표현한다. 홈은 긴 dashboard 문서가 아니라 한 장씩 넘기는 학습 기회 큐다.

### Review Before Discovery

복습 due가 있으면 discovery는 복습을 방해하지 않는다.

추천곡 단어장 생성과 새 곡 검색 제안은 복습 단어 사이에 끼워 넣지 않는다. due 복습을 모두 끝낸 뒤 `모든 단어를 복습했어요` 카드에서 다음 행동으로 제안한다.

### Recommendation Creates Word Cards

추천곡은 별도 카드 타입이 아니다. `복습 완료 카드`의 action으로만 노출하고, 사용자가 `추천곡의 단어 학습`을 탭하면 그 순간 추천곡의 단어장을 생성한다. 생성이 끝나면 해당 단어장의 단어들을 기존 `단어 카드` 타입으로 표시한다.

나쁜 방향:

```text
추천곡 카드
Lemon · 米津玄師
```

좋은 방향:

```text
복습 완료 카드
[추천곡의 단어 학습]

탭하면 추천곡 단어장 생성

단어 카드
Lemon · 米津玄師
夢 · ゆめ · 꿈
```

`새 곡 검색`은 홈 카드 타입이 아니다. `복습 완료 카드`의 action으로만 노출하고, 탭하면 홈 stack에는 변화 없이 검색탭으로 이동한다.

## 홈 카드 타입

홈탭의 카드 타입은 두 가지뿐이다.

1. `단어 카드`
2. `복습 완료 카드`

추천곡에서 온 단어든, 기존 due 복습 단어든, 사용자가 새로 만든 단어장에 들어간 단어든 모두 `단어 카드`다. source와 생성 경로는 다를 수 있지만 카드 타입은 늘 같다.

### 단어 카드

단어를 복습하거나 새로 배우는 카드다.

- 단어, 읽기, 가사 예문, 곡 출처를 보여준다.
- front 상태에서는 뜻을 숨기고 `뜻 보기`를 primary action으로 둔다.
- back 상태에서는 뜻과 FSRS 평가 버튼을 보여준다.
- rating 선택 후 위로 스와이프하면 다음 단어 카드로 이어진다.
- streak은 별도 큰 카드가 아니라 카드 안의 작은 문구로 붙인다.
- 추천곡의 단어도 먼저 추천곡 단어장을 생성한 뒤, 그 단어장에 속한 단어를 이 카드 타입으로 보여준다.

권장 문구:

- `7일째 이어가는 중`
- `스트릭 유지됨`
- `夜に駆ける에서 다시 볼 단어`

### 복습 완료 카드

현재 홈 stack에서 처리할 due 단어를 모두 끝냈을 때 표시한다.

필수 문구:

```text
모든 단어를 복습했어요
```

역할:

- streak 유지 완료를 알려준다.
- 사용자가 다음에 무엇을 볼지 고른다.
- `추천곡의 단어 학습`을 탭하면 그 순간 추천곡의 단어장을 생성하고, 생성된 단어들로 다음 `단어 카드`들을 띄운다.
- `새 곡 검색`을 탭하면 홈 stack 상태는 유지한 채 검색탭으로 이동한다.
- `계속 복습`은 기존 full review flow로 연결할 수 있다.

선택지:

- `추천곡의 단어 학습`
- `새 곡 검색`
- `계속 복습`

## 카드 순서 규칙

### due가 있는 경우

```text
1. 단어 카드
2. 단어 카드
3. 단어 카드
...
N. 복습 완료 카드
N+1. 추천곡 선택 시 생성된 단어 카드들
```

- due가 남아 있는 동안 추천곡 단어장 생성이나 검색 진입을 자동 삽입하지 않는다.
- 사용자가 명시적으로 검색 아이콘을 누르는 것은 예외다.
- due를 모두 끝내면 `복습 완료 카드`를 표시한다.

### due가 없는 경우

```text
1. 복습 완료 카드
2. 추천곡의 단어 학습 선택 시 생성된 단어 카드들
```

- due가 없으면 `복습 완료 카드`를 표시하고 추천곡 단어장 생성 또는 새 곡 검색을 유도한다.
- 완전 신규 유저도 검색 카드나 추천곡 카드를 직접 보지 않는다. `복습 완료 카드`에서 `추천곡의 단어 학습` 또는 `새 곡 검색`을 선택하게 한다.
- 기존에 추천곡 선택으로 생성된 단어장이 있고 아직 홈 stack에서 처리할 단어가 남아 있다면 `단어 카드`를 이어서 표시할 수 있다.

## 인터랙션 모델

### 기본 제스처

- 단어 카드 front 탭 또는 `뜻 보기` 탭: 단어 카드 back 공개
- 단어 카드 back의 rating 탭: rating 선택
- rating이 선택된 단어 카드 back에서 위로 스와이프: 선택한 rating 저장 + 다음 카드 진행
- 복습 완료 카드의 action 탭: 해당 action 즉시 실행
- 상단 검색 아이콘: 즉시 검색 진입

홈의 기본 이동은 세로 문서 스크롤이 아니라 카드 단위 전환이다. 카드 stack은 단방향 진행 모델이며, 이전 카드로 되돌아가는 제스처나 기능은 제공하지 않는다. 위로 스와이프는 단어 카드 back에서 rating이 명시 선택된 경우에만 다음 카드 진행으로 동작한다.

### FSRS 평가

단어 카드는 front/back 두 상태를 가진다.

- front에서 카드 또는 `뜻 보기`를 탭하면 back으로 전환한다.
- back에서는 명시적인 rating 버튼을 탭해 rating을 먼저 선택한다.
- rating 선택 후 위로 스와이프하면 선택한 rating을 저장하고 다음 카드로 넘어간다.
- rating을 선택하지 않은 상태에서 위로 스와이프하면 카드는 넘어가지 않고 rating 선택을 요구한다.

단어 카드 back의 rating 선택지는 다음 4개다.

- `다시`
- `어려움`
- `알고 있음`
- `쉬움`

좌우 스와이프 빠른 평가는 이번 UX에 포함하지 않는다. rating은 반드시 버튼 탭으로 명시 선택하고, 다음 카드 진행은 위로 스와이프로만 수행한다.

### 복습 완료 후 선택

`복습 완료 카드`에서 사용자가 `추천곡의 단어 학습`을 탭하면 그 순간 추천곡의 단어장을 생성하고, 생성된 단어들로 다음 `단어 카드`들을 띄운다.

`새 곡 검색`을 탭하면 홈 stack에는 새 카드를 추가하지 않고 검색탭으로 이동한다.

예:

```text
모든 단어를 복습했어요
[추천곡의 단어 학습]
[새 곡 검색]
```

다음 카드:

```text
단어 카드
Lemon · 米津玄師
夢 · ゆめ · 꿈
```

## 주요 플로우

### 복습 due가 있는 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 due 단어 중 하나를 `단어 카드`로 표시한다.
3. 사용자는 뜻을 떠올린 뒤 카드 또는 `뜻 보기`를 탭한다.
4. 시스템은 같은 카드에서 뜻과 FSRS rating을 표시한다.
5. 사용자가 rating을 탭해 선택한다.
6. 사용자가 위로 스와이프한다.
7. 시스템은 선택한 rating을 저장하고 다음 단어 카드를 표시한다.
8. 모든 due 단어를 끝내면 `모든 단어를 복습했어요` 카드를 표시한다.
9. 사용자는 `추천곡의 단어 학습` 또는 `새 곡 검색`을 탭한다.
10. `추천곡의 단어 학습`을 탭한 경우 시스템은 추천곡 단어장을 생성하고 해당 단어장의 첫 `단어 카드`를 표시한다.
11. `새 곡 검색`을 탭한 경우 시스템은 홈 stack을 변경하지 않고 검색탭으로 이동한다.

### due가 없고 저장 단어장이 있는 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 `스트릭 유지됨` 또는 오늘 완료 상태를 작은 문구로 보여준다.
3. 시스템은 `복습 완료 카드`를 표시한다.
4. 사용자는 `추천곡의 단어 학습`, `새 곡 검색`, `계속 복습` 중 하나를 탭한다.
5. `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 해당 단어장의 첫 `단어 카드`를 표시한다.
6. `새 곡 검색`을 탭하면 시스템은 홈 stack을 변경하지 않고 검색탭으로 이동한다.

### 완전 신규 유저

1. 사용자가 홈탭에 진입한다.
2. 시스템은 `복습 완료 카드`를 표시한다.
3. 사용자는 `추천곡의 단어 학습` 또는 `새 곡 검색`을 선택한다.
4. `추천곡의 단어 학습`을 탭하면 시스템은 추천곡 단어장을 생성하고 첫 `단어 카드`를 표시한다.
5. 사용자는 이 앱이 곡 가사에서 단어를 배우는 앱이라는 것을 첫 `단어 카드`에서 이해한다.

## 사이드케이스 플로우

### due 조회 실패

1. 홈 진입 시 due 조회가 실패한다.
2. 시스템은 홈 전체를 오류 화면으로 만들지 않는다.
3. 사용 가능한 추천곡이 있으면 `복습 완료 카드`를 통해 추천곡 단어장 생성 또는 새 곡 검색을 제안한다.
4. 복습 상태는 다음 포커스 또는 명시 재시도 때 다시 조회한다.

### 추천곡이 없음

1. 추천곡 API가 빈 목록을 반환한다.
2. 시스템은 `복습 완료 카드`에서 `추천곡의 단어 학습` 선택지를 숨기거나 비활성화한다.
3. 사용자는 `새 곡 검색`을 통해 검색탭으로 이동할 수 있다.

### 단어 미리보기를 만들 수 없는 추천곡

1. 추천곡에 노출 가능한 단어/가사 예문이 없다.
2. 시스템은 해당 곡을 추천곡 단어장 생성 후보로 사용하지 않는다.
3. 다른 추천곡 후보가 없으면 `추천곡의 단어 학습` 선택지를 숨기거나 비활성화한다.

## 데이터 요구사항

기존 데이터로 가능한 영역:

- flashcard due 카드
- FSRS rating
- streak/home stats
- 추천곡 목록
- 최근 들은 곡
- SongDetail 분석 결과가 있는 곡의 단어/가사 예문

추가 검토가 필요한 영역:

- 홈용 추천곡 단어장 생성 후보 API
- 홈 stack을 구성하는 서버 주도 feed API가 필요한지, 클라이언트 조합으로 충분한지

## 수용 기준

- [ ] 홈 진입 시 주요 콘텐츠는 하나의 카드로 표시된다.
- [ ] due가 있으면 첫 카드는 `단어 카드`다.
- [ ] due가 남아 있는 동안 추천곡 단어장 생성이나 검색 진입 제안이 자동으로 끼어들지 않는다.
- [ ] `단어 카드`는 단어, 읽기, 곡 출처, 가사 예문, `뜻 보기` action을 표시한다.
- [ ] 뜻 확인 후 같은 카드에서 FSRS rating을 선택할 수 있다.
- [ ] rating을 선택해도 즉시 다음 카드로 넘어가지 않는다.
- [ ] rating이 선택된 상태에서 위로 스와이프하면 선택한 rating을 저장하고 다음 단어 카드가 표시된다.
- [ ] rating을 선택하지 않은 상태에서 위로 스와이프하면 다음 카드로 넘어가지 않는다.
- [ ] 이전 카드로 되돌아가는 제스처나 기능은 제공하지 않는다.
- [ ] due를 모두 처리하면 `모든 단어를 복습했어요` 카드가 표시된다.
- [ ] 완료 카드는 `추천곡의 단어 학습`, `새 곡 검색`, `계속 복습` action을 포함한다.
- [ ] 사용자가 `추천곡의 단어 학습`을 탭하면 추천곡의 단어장을 생성하고, 생성된 단어장의 첫 `단어 카드`를 표시한다.
- [ ] 사용자가 `새 곡 검색`을 탭하면 홈 stack 상태를 바꾸지 않고 검색탭으로 이동한다.
- [ ] 추천곡에서 생성된 단어도 별도 카드 타입이 아니라 `단어 카드`로 표시된다.
- [ ] 홈의 주요 UI는 섹션 목록이 아니라 카드 stack으로 동작한다.
- [ ] SongDetail의 UI와 플로우는 이번 작업에서 변경하지 않는다.

## 결정 경계

구현자가 별도 제품 확인 없이 결정할 수 있는 항목:

- 홈 카드의 정확한 높이, 간격, 모서리, 버튼 배치
- 카드 전환 애니메이션의 세부 수치
- 첫 구현에서 좌우 스와이프 빠른 평가를 제외하고 버튼 rating 선택만 제공하는 결정
- 홈 stack을 클라이언트에서 조합할지, 기존 API를 묶는 얇은 home API를 둘지에 대한 기술적 선택
- 추천곡 후보가 없을 때 `추천곡의 단어 학습` 선택지를 숨길지 비활성화할지에 대한 UI 처리

제품 확인이 필요한 변경:

- due 복습 카드 사이에 discovery 카드를 자동 삽입하는 정책
- streak 유지 조건 변경
- SongDetail 진입/생성 완료 후 목적지 변경
- 홈을 SNS식 무한 피드로 확장하는 결정
