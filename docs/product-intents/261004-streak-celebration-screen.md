# 연속 학습 축하 전체 화면

Pencil `app-rn/japanese-vocabulary.pen` 의 `S1` / `S2` / `S3` 프레임과 `spec/StreakCelebration` 이 원본이다.
`S3` 는 어제가 프리즈였을 때의 점화 전 키프레임이고, 점화 시퀀스 전체는 spec 의 두 줄짜리 스트립에 있다.

## 무엇

오늘 첫 rating 직후 떠 있다 사라지던 플로팅 배너(260918 A-1)를 폐기하고, 전체 화면 축하로 바꾼다.
배너는 학습 흐름을 끊지 않는 대신 거의 읽히지 않았다. 연속 학습은 이 앱이 유저에게 각인시키려는
단 하나의 습관이라, 하루에 한 번은 화면 전체를 쓸 값을 한다.

리뷰 화면 위를 덮는 어두운 ember 톤. 밝은 것은 불꽃과 CTA 둘뿐이다.

- 꺼져 있던 불 아이콘이 점화되며 빛무리와 불티가 퍼진다
- `N` `일 연속` — 숫자는 N-1 에서 N 으로 넘어가며 한 번 튄다
- 감탄 한 줄 + 격려 한 줄
- 지난 7일 슬롯 — 학습함(주황 불꽃) / 프리즈(파란 눈송이) / 미학습(빈 원), 오늘 칸은 더 크게 점화
- `이어서 학습하기` CTA — 닫고 다음 카드로 돌아간다

CTA 는 앱 공통 초록이 아니라 크림이다. 배경이 전부 따뜻한 어둠이라 초록이 겉돈다.

## 문구

N = 오늘 포함 연속 일수. freeze 로 이어진 경우도 이어감과 같다.

| 상황 | 감탄 | 격려 |
|---|---|---|
| 이어감 (N≥2) | `연속 학습 기록을 이어 갔어요!` | `내일도 학습하면 {N+1}일 연속이에요` |
| 첫날 (N=1, 이전 기록 없음) | `연속 학습을 시작했어요!` | `내일도 학습하면 2일 연속이에요` |
| 끊긴 뒤 재시작 (N=1, 이전 기록 있음) | `연속 학습을 다시 시작했어요!` | `내일도 학습하면 2일 연속이에요` |

## 모션

게임·아니메 연출처럼 과장한다. 불꽃이 화면을 꽉 채운 채 점화된 뒤 제자리로 날아가 앉고, 나머지 요소는 그 다음에 하나씩 등장한다. CTA 까지 약 5.2초.

| 시점 | 무엇 |
|---|---|
| 0ms | 어두운 배경이 페이드 인 (260ms) |
| 120 → 680ms | 화면을 꽉 채운 꺼진 불이 살짝 움츠러들며 점점 세게 떤다. 어제가 프리즈였으면 꺼진 불 대신 눈 결정이고 배경도 푸른 톤 |
| 720ms | 점화 — 속불부터 밑동에서 솟아 0.35초 만에 바깥 겹까지 번지고, 꺼진 불은 그 사이 사그라들고, 눈 결정은 주황으로 달아오른 뒤 밑으로 녹아 주저앉으며 사라지고, 푸른 배경도 붉은 배경으로 바뀐다 |
| 940ms | 확 치솟음 — 불꽃 키가 1.4배로 훌쩍 솟았다 내려앉고, 밑에서 뜨거운 빛 덩어리가 부풀며, 섬광·낮은 울림과 함께 불티 18개가 위로 솟구친다 |
| 1950 → 2590ms | 불꽃이 디자인 자리·크기로 날아가 살짝 지나쳤다 앉고, 앉는 순간 빛무리가 한 번 부푼다 |
| 2450ms | `N-1 일 연속` 이 살짝 떠오르며 조용히 나타난다 |
| 3000ms | `N 일 연속` 이 2.4배에서 내리꽂히고, N-1 은 그 사이 사라진다 |
| 3400 / 3580ms | 감탄 → 격려 순으로 올라온다 |
| 3950ms~ | 지난 7일 카드가 올라오고 슬롯이 왼쪽부터 90ms 간격으로 팝인, 오늘 칸은 한 박자 늦게 1.5배로 점화 |
| 5200ms | CTA 가 튀어 오르며 등장 |

불꽃 3겹과 너울 시계는 `flame.ts` 가 들고, 연속 학습 상세 히어로(`FlameMark`)가 같은 것을 쓴다. 그쪽은 배경이 밝아 빛무리만 묽게 깐다.

점화 뒤 불꽃은 계속 타오른다 — 3겹이 같은 너울을 타되 안쪽이 조금 늦게 따라오며 밑동을 축으로 늘었다 줄고, 불씨가 천천히 솟는다. 해제는 260ms 페이드 아웃.

## 노출 규칙

오늘 첫 rating 직후 1회. 같은 날 두 번째 rating 부터는 뜨지 않고, 하루 경계는 04:00.
판정은 260918 그대로 `studiedToday` 가 `false` → `true` 로 바뀌는 그 한 번이다.

CTA 와 Android 뒤로가기로만 닫힌다. 스스로 사라지지 않는다.

## 서버 지원

**서버 변경 없다.** 주간 슬롯은 `GET /api/study-stats/home` 이 이미 주는 `weekDots` 를 그대로 쓴다.
`weekDots` 가 비어 있으면 슬롯 줄만 빠지고 나머지는 그대로 나온다.
