# Product Intent: SongDetail Learning Overview

## 사용자 목표

- 사용자는 곡의 제목, 아티스트, 단어, 가사를 확인할 수 있다.
- 사용자는 이 곡에서 중요한 단어를 빠르게 이해할 수 있다.
- 사용자는 이 곡을 얼마나 학습하고 있는지 알 수 있다.
- 사용자는 곡의 현재 학습 상태에 맞는 플래시카드 학습으로 이어갈 수 있다.
- 사용자는 필요할 때 전체 가사를 확인할 수 있다.

## 현재 문제

- 현재 `SongDetailScreen`은 곡 정보, 가사, 단어 목록, 단어 담기 동작이 섞여 있다.
- 단어 목록이 뜻을 먼저 보여줘서 사용자가 학습하기 전에 이미 답을 확인한다.
- 사용자는 이 곡으로 무엇을 해야 하는지보다 어떤 단어를 담아야 하는지를 먼저 판단해야 한다.
- 중요한 단어와 전체 단어 목록의 역할이 분리되지 않아 곡의 핵심이 한눈에 들어오지 않는다.
- 곡의 현재 학습 상태와 다음 학습 행동이 화면 전체의 기준으로 드러나지 않는다.
- `단어장 만들기`, `모든 단어 담기`, `48개 담기` 같은 문구가 학습 시작을 관리 작업처럼 느끼게 한다.
- 가사 확인 경험이 강해질수록 전체 가사 소비 화면으로 인식될 위험이 있다.

## 성공 기준

- 사용자는 `SongDetailScreen`에서 이 곡이 어떤 곡인지 이해한다.
- 사용자는 홈 탭에서 이 곡의 핵심 단어와 자신의 이해도를 파악한다.
- 사용자는 단어 탭에서 이 곡의 전체 단어 목록을 확인한다.
- 사용자는 `단어장`이나 `담기` 개념을 거치지 않고 학습을 시작한다.
- 사용자는 곡의 학습 상태에 따라 학습 시작 또는 오늘의 복습으로 진입한다.
- 사용자는 곡의 핵심 단어에서 뜻을 먼저 보지 않고 학습으로 진입한다.
- 전체 가사는 기본 화면이 아니라 사용자가 연 별도 영역에서 확인된다.
- `SongDetailScreen`은 곡 정보 확인과 플래시카드 학습 진입점으로 인식된다.

## Scope

- `SongDetailScreen`의 제품 역할 재정의
- 곡 제목, 아티스트, 단어, 가사의 정보 구조
- 곡별 학습 가능 상태와 다음 학습 행동의 노출
- 홈 탭의 곡 요약 정보 구조
- 홈 탭의 중요 단어 카드 진입점 (뜻을 가린 카드에서 학습으로 진입)
- 홈 탭의 곡 이해도 정보
- 단어 탭의 전체 단어 목록
- 곡 기반 학습 시작 진입점
- due가 있는 곡의 오늘 복습 진입점
- 기본 화면과 분리된 전체 가사 확인 진입점

## Non-goal

- 홈탭 카드 스택 구현
- `StudySessionScreen`의 카드 학습 UX 구현
- 검색탭, 추천곡, 최근 들은 곡 정보구조 변경
- 프로필탭 또는 학습 통계 화면 구현
- FSRS 알고리즘 변경
- 단어장, flashcard, deck 도메인 수명주기 변경
- 곡 난이도 통계의 핵심 정보화
- 대표 표현 또는 가사 맥락 미리보기 제공
- 가사 라이선스 문제의 법적 해결
- 가사 제공 정책 또는 provider 변경
- 단어 목록 정렬, 필터, 편집 기능 고도화
- 학습 진행 중 상태의 별도 진입 문구 분기
- 학습 후보가 없는 곡의 별도 상태 화면

## 주요 플로우

1. 사용자가 검색탭, 추천곡, 최근 들은 곡 중 하나에서 곡을 선택한다.
2. 시스템은 `SongDetailScreen`에서 곡 정보와 현재 학습 상태를 보여준다.
3. 사용자는 홈 탭에서 뜻이 가려진 핵심 단어 카드와 곡 이해도를 확인한다.
4. 사용자가 핵심 단어 카드 또는 다음 학습 행동을 선택한다.
5. 시스템은 선택한 단어를 맨 앞에 두고 해당 곡의 플래시카드 학습 세션으로 진입시킨다.
6. 결과적으로 사용자는 곡 정보 확인에서 카드 학습으로 이어진다.

## 사이드케이스 플로우

### 전체 단어를 확인하는 경우

1. 사용자가 단어 탭을 선택한다.
2. 시스템은 이 곡의 전체 단어 목록을 보여준다.
3. 결과적으로 사용자는 요약된 중요 단어 밖의 단어까지 확인할 수 있다.

### 오늘 복습할 단어가 있는 곡

1. 사용자가 due 단어가 있는 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 오늘 다시 볼 단어와 복습 행동을 보여준다.
3. 사용자가 복습을 선택한다.
4. 결과적으로 사용자는 이 곡의 due 단어 학습 세션으로 진입한다.

### 학습할 단어가 준비되지 않은 곡

1. 사용자가 분석이 끝나지 않은 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 학습 준비 상태를 보여준다.
3. 결과적으로 사용자는 곡 정보는 확인할 수 있지만 학습 세션은 시작하지 않는다.

### 가사 확인이 필요한 경우

1. 사용자가 곡 이해를 위해 가사 맥락을 확인한다.
2. 사용자가 전체 가사를 열기로 선택한다.
3. 시스템은 현재 화면 위의 별도 영역에서 전체 가사를 보여준다.
4. 결과적으로 기본 화면은 학습 진입점으로 남고, 전체 가사는 필요할 때만 열린다.

## 학습 상태

`SongDetailScreen`은 세 가지 학습 상태만 구분한다.

| 상태 | 조건 | 다음 학습 행동 |
| --- | --- | --- |
| 시작 전 | 분석 완료, due 없음 | 이 곡으로 학습 시작 |
| 오늘 복습 | 분석 완료, due 있음 | 오늘 복습 N개 |
| 분석 준비 중 | 분석 미완료 | 없음 (준비 상태만 노출) |

이미 학습을 시작했지만 오늘 due가 없는 곡은 별도 상태로 나누지 않고 `시작 전`과 같은 진입 문구를 쓴다.
학습 후보가 없는 곡도 별도 화면을 만들지 않는다.
