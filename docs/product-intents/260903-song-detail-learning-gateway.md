# Product Intent: SongDetail Learning Gateway

## 사용자 목표

- 사용자는 탐색한 곡이 학습할 만한 곡인지 판단할 수 있다.
- 사용자는 단어장 관리 개념을 의식하지 않고 이 곡의 학습을 시작할 수 있다.
- 사용자는 이미 시작한 곡에서 남은 학습이나 오늘의 복습으로 이어갈 수 있다.
- 사용자는 필요할 때 전체 가사를 확인할 수 있다.

## 현재 문제

- 현재 `SongDetailScreen`은 곡 정보, 가사, 단어 목록, 단어 담기 동작이 섞여 있다.
- 사용자는 이 곡으로 무엇을 해야 하는지보다 어떤 단어를 담아야 하는지를 먼저 판단해야 한다.
- `단어장 만들기`, `모든 단어 담기`, `48개 담기` 같은 문구가 학습 시작을 관리 작업처럼 느끼게 한다.
- 가사 확인 경험이 강해질수록 전체 가사 소비 화면으로 인식될 위험이 있다.

## 성공 기준

- 사용자는 `SongDetailScreen`에서 이 곡으로 배울 수 있는 내용을 이해한다.
- 사용자는 `단어장`이나 `담기` 개념을 거치지 않고 학습을 시작한다.
- 사용자는 곡의 학습 상태에 따라 시작, 이어서 학습, 오늘의 복습 중 하나로 자연스럽게 진입한다.
- 전체 가사는 기본 화면이 아니라 사용자가 연 별도 영역에서 확인된다.
- `SongDetailScreen`은 가사 소비보다 곡 기반 학습 진입점으로 인식된다.

## Scope

- `SongDetailScreen`의 제품 역할 재정의
- 곡별 학습 가능 상태와 학습 진행 상태의 노출
- 곡 기반 학습 시작 진입점
- 이미 시작한 곡의 이어서 학습 진입점
- due가 있는 곡의 오늘 복습 진입점
- 학습 전 확인할 곡 정보와 학습 포인트의 정보 구조
- 기본 화면과 분리된 전체 가사 확인 진입점

## Non-goal

- 홈탭 카드 스택 구현
- `StudySessionScreen`의 카드 학습 UX 구현
- 검색탭, 추천곡, 최근 들은 곡 정보구조 변경
- 프로필탭 또는 학습 통계 화면 구현
- FSRS 알고리즘 변경
- 단어장, flashcard, deck 도메인 수명주기 변경
- 가사 라이선스 문제의 법적 해결
- 가사 제공 정책 또는 provider 변경
- 단어 목록 정렬, 필터, 편집 기능 고도화

## 주요 플로우

1. 사용자가 검색탭, 추천곡, 최근 들은 곡 중 하나에서 곡을 선택한다.
2. 시스템은 `SongDetailScreen`에서 곡 정보와 학습 가능 상태를 보여준다.
3. 사용자는 이 곡으로 배울 수 있는 내용을 확인한다.
4. 사용자가 학습 시작을 선택한다.
5. 시스템은 필요한 학습 데이터를 준비하고 이 곡의 학습 세션으로 진입시킨다.
6. 결과적으로 사용자는 곡 탐색에서 카드 학습으로 이어진다.

## 사이드케이스 플로우

### 이미 학습을 시작한 곡

1. 사용자가 이전에 학습을 시작한 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 기존 진행 상태를 보여준다.
3. 사용자가 이어서 학습을 선택한다.
4. 결과적으로 사용자는 이 곡의 남은 학습 세션으로 이어진다.

### 오늘 복습할 단어가 있는 곡

1. 사용자가 due 단어가 있는 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 오늘 다시 볼 단어가 있음을 보여준다.
3. 사용자가 복습을 선택한다.
4. 결과적으로 사용자는 이 곡의 due 단어 학습 세션으로 진입한다.

### 학습할 단어가 준비되지 않은 곡

1. 사용자가 분석이 끝나지 않은 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 학습 준비 상태를 보여준다.
3. 결과적으로 사용자는 곡 정보는 확인할 수 있지만 학습 세션은 시작하지 않는다.

### 학습할 단어가 없는 곡

1. 사용자가 분석 결과 학습 후보가 없는 곡의 `SongDetailScreen`에 진입한다.
2. 시스템은 이 곡으로 시작할 학습이 없음을 보여준다.
3. 결과적으로 사용자는 다른 곡을 탐색할 수 있다.

### 가사 확인이 필요한 경우

1. 사용자가 곡 이해를 위해 가사 맥락을 확인한다.
2. 사용자가 전체 가사를 열기로 선택한다.
3. 시스템은 현재 화면 위의 별도 영역에서 전체 가사를 보여준다.
4. 결과적으로 기본 화면은 학습 진입점으로 남고, 전체 가사는 필요할 때만 열린다.
