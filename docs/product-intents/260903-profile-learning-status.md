# Product Intent: Profile Learning Status

## 사용자 목표

- 사용자는 자신의 현재 학습 상태를 확인할 수 있다.
- 사용자는 자신의 프로필 맥락에서 학습 현황을 볼 수 있다.
- 사용자는 곡별 학습 진행 상황을 비교할 수 있다.
- 사용자는 날짜별 학습 활동 기록을 확인할 수 있다.
- 사용자는 스트릭을 통해 학습을 이어갈 동기를 얻을 수 있다.

## 현재 문제

- 현재 프로필탭은 계정 관리 동작과 학습 통계가 함께 있어 화면의 주목점이 흐리다.
- 사용자는 전체 학습 상태, 활동 기록, 곡별 진행 상태를 한곳에서 파악하기 어렵다.
- 단어장이 많아질수록 어떤 곡을 얼마나 학습했는지 확인하기 어렵다.
- 현재 화면 안에서 학습 기록과 곡별 단어장 목록이 같은 무게로 노출되어, 화면이 `나의 학습 상태 요약`인지 `단어장 목록`인지 불분명하다.

## 제품 역할

프로필탭은 계정 관리 화면이 아니라 `나의 학습 상태를 한눈에 확인하는 학습 대시보드`다.

- 프로필 식별 정보는 유지하되 화면의 주인공이 아니다.
- 첫 화면의 핵심은 오늘 상태, 누적 요약, 활동 패턴이다.
- 곡별 학습 현황은 필요하지만 첫 화면 전체를 차지하는 목록이 아니라 `대표 요약 + 전체 탐색 진입점`으로 다룬다.
- 곡 단어장이 많아지는 경우의 해법은 프로필 첫 화면에 긴 목록을 두는 것이 아니라, 별도 곡별 현황 화면에서 검색/정렬/페이지네이션을 제공하는 것이다.
- 설정, 로그아웃, 프로필 수정, 인증 관련 동작은 학습 현황보다 낮은 우선순위로 설정 화면 또는 작은 아이콘 진입점에 둔다.

## 성공 기준

- 사용자는 프로필탭에서 오늘의 학습 상태와 누적 진행을 이해한다.
- 사용자는 자신의 학습 활동 패턴을 확인할 수 있다.
- 사용자는 곡별 학습 현황을 확인하고 필요한 곡을 찾을 수 있다.
- 사용자는 최대 100개의 곡 단어장이 있어도 현황 확인을 포기하지 않는다.
- 프로필탭은 계정 관리보다 학습 현황 화면으로 인식된다.

## Scope

- 프로필탭의 제품 역할 재정의
- 기존 프로필 식별 정보의 유지
- 스트릭과 전체 학습 요약의 노출
- 날짜별 학습 활동 기록의 노출
- 프로필탭 안의 곡 단어장별 학습 현황 요약 노출
- 별도 곡별 현황 화면의 탐색 가능 상태
- 학습 현황의 비어 있음, 로딩, 오류 상태

## Non-goal

- 홈탭 카드 스택 구현
- 검색탭 탐색 UX 구현
- `SongDetailScreen`의 학습 시작 UX 구현
- `StudySessionScreen` 구현
- 계정 설정, 프로필 편집, 인증 정책 변경
- 스트릭 계산 규칙 변경
- 곡 단어장 생성·삭제 수명주기 변경
- 복습 알고리즘 또는 진도 산식 변경

## 정보 분류와 우선순위

### 1순위: 오늘의 학습 상태

프로필탭 진입 직후 사용자가 가장 먼저 이해해야 하는 정보다.

- 현재 스트릭
- 오늘 학습량 / 일일 목표 대비 진행
- 오늘 복습할 단어 수
- 오늘 상태: 아직 안 함, 진행 중, 목표 달성, 스트릭 끊김

### 2순위: 누적 학습 요약

사용자가 자신의 전체 진행을 빠르게 판단하는 정보다.

- 전체 저장 단어 수
- 외운 단어 / 학습 중 / 새 단어 비율
- 총 학습일
- 최장 스트릭

### 3순위: 활동 패턴

사용자가 날짜별 학습 습관을 확인하는 정보다.

- 이번 주 활동 요약
- 날짜별 학습 기록 heatmap
- 프리즈 사용 여부

`이번 주 활동`과 `학습 기록 heatmap`은 같은 목적을 반복하지 않도록 계층을 나눈다. 상단에는 이번 주 요약을 두고, heatmap은 더 긴 기간의 패턴 확인용으로 낮은 밀도로 둔다.

### 4순위: 곡별 학습 현황

사용자가 곡별 진행 차이를 비교하고 필요한 곡을 찾기 위한 정보다. 단, 프로필 첫 화면에서는 전체 목록을 펼치지 않는다.

- 프로필탭에는 대표 곡 3~5개만 노출한다.
- 대표 곡은 `복습 필요 많은 곡`, `최근 학습 곡`, `완료에 가까운 곡`을 우선한다.
- 각 곡 행은 곡명, 아티스트, 총 단어 수, 복습 필요 수, 완료율만 보여준다.
- 전체 곡 단어장 목록은 `곡별 현황 전체 보기`로 진입한다.

### 5순위: 프로필과 계정 관리

프로필 맥락을 제공하되 학습 현황을 밀어내지 않아야 하는 정보다.

- 이름, 핸들, 아바타
- 프로필 수정 아이콘
- 설정 진입 아이콘

프로필 첫 화면에서 낮춰야 하는 정보:

- 100개까지 이어지는 전체 곡 단어장 리스트
- 단어장 삭제, 편집, 직접 관리 액션
- 로그아웃, 인증, 계정 정책 동작
- 프리즈 설명문 전체
- 곡별 단어 상세 목록
- 전체 단어장과 곡별 단어장 목록의 반복 노출

## 곡별 현황 정렬

프로필탭의 대표 곡 기본 정렬:

1. `dueCount > 0`인 곡을 복습 필요 수 내림차순으로 노출한다.
2. due가 없지만 최근 학습한 곡을 노출한다.
3. 완료율이 높은 곡을 노출해 거의 끝난 곡을 확인하게 한다.

곡별 현황 전체 화면의 기본 정렬:

1. 복습 필요 곡: `dueCount` 내림차순
2. 진행 중 곡: 최근 학습일 내림차순
3. 완료 임박 곡: 완료율 내림차순
4. 새 단어장: 생성일 또는 최근 추가일 내림차순
5. 완료/비활성 곡

전체 화면은 최대 100개 곡 단어장을 포기하지 않고 훑을 수 있도록 `복습 필요`, `최근`, `진행률`, `가나다` 정렬을 제공한다.

## 주요 플로우

1. 사용자가 프로필탭에 진입한다.
2. 시스템은 작은 프로필 식별 정보 아래에 오늘의 학습 상태를 가장 먼저 보여준다.
3. 시스템은 누적 학습 요약과 활동 기록을 보여준다.
4. 시스템은 대표 곡별 학습 현황과 전체 보기 진입점을 보여준다.
5. 사용자는 자신의 학습 흐름, 활동 패턴, 곡별 진행 차이를 확인한다.
6. 결과적으로 사용자는 현재 상태를 이해하고 다음 학습 판단을 할 수 있다.

## 사이드케이스 플로우

### 곡 단어장이 많은 경우

1. 사용자가 여러 곡 단어장을 가진 상태로 프로필탭에 진입한다.
2. 시스템은 프로필탭에서 대표 곡별 현황만 보여주고 전체 보기 진입점을 제공한다.
3. 사용자가 전체 보기를 탭한다.
4. 시스템은 별도 곡별 현황 화면에서 정렬과 탐색이 가능한 목록을 보여준다.
5. 결과적으로 사용자는 원하는 곡의 학습 현황을 찾을 수 있다.

### 학습 기록이 없는 경우

1. 사용자가 학습 기록 없이 프로필탭에 진입한다.
2. 시스템은 아직 확인할 학습 현황이 없음을 보여준다.
3. 결과적으로 사용자는 곡 탐색을 시작할 수 있다.

### 스트릭이 끊긴 경우

1. 사용자가 스트릭이 끊긴 상태로 프로필탭에 진입한다.
2. 시스템은 현재 스트릭 상태를 보여준다.
3. 결과적으로 사용자는 다시 학습을 이어갈 수 있다.

### 학습 현황을 불러오지 못한 경우

1. 사용자가 프로필탭에 진입한다.
2. 시스템은 학습 현황을 불러오지 못했음을 알려준다.
3. 결과적으로 사용자는 화면을 다시 확인할 수 있다.
