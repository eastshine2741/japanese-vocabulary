# Product Intent: Streak Commitment

연속 학습을 "세션을 끝낸 보상"이 아니라 "첫 카드 한 장의 즉시 결과"로 만들고, 홈에 들어온 순간부터 오늘 학습을 했는지 아직인지가 보이게 한다.

용어: 사용자에게 보이는 이름은 **연속 학습**. "스트릭"은 이 문서 안의 내부 용어다. 문구는 사람이 말로 하는 표현만 쓴다.

## 데이터 근거 (prod, 2026-09-18)

- 가입 59명 → 복습 시작 28명 (47%) → 이틀째 복습 4명 (15%) → 4일 이상 2명.
- 단어는 곡을 열 때 30~60장 일괄 저장되고 첫 복습은 그 직후 시작된다. 유저는 "복습하러" 온 게 아니라 곡을 열었더니 카드가 나온 것.
- 1일만 학습한 유저 18명의 첫 세션: 중앙값 카드 5장, 1분 안팎. 5명은 1장만 보고 이탈.
- 홈 스택의 `복습 완료 카드`는 곡의 due를 다 비워야 나오는데 새 곡은 due가 30~60장이라 도달한 유저는 4명뿐.
- 유저별 학습 시각은 일정하지 않다. 첫 세션 시각의 쏠림은 릴스 업로드 시각을 따른 유입 시각이지 습관이 아니다.
- 하루의 경계는 자정이 아니라 KST 04:00이다. 새벽 학습은 전날로 친다.

결론: 세션 종료 화면에 연속 학습을 걸면 대부분의 유저가 보지 못한다. 하루 첫 카드에 rating을 매기는 시점이 모든 학습 유저가 통과하는 유일한 지점이다.

## 사용자 목표

- 사용자는 카드 한 장만 넘겨도 오늘 연속 학습이 이어졌음을 그 자리에서 안다.
- 사용자는 홈에 들어오자마자 오늘 학습을 했는지 아직인지 안다.
- 사용자는 학습 흐름을 멈추지 않고 위 두 가지를 확인한다.

## 현재 문제

- 연속 학습은 하루 첫 리뷰 시 이미 쌓이지만, 사용자는 홈 헤더의 정적 숫자(`🔥 N일 연속`) 외에 그 사실을 알 방법이 없다.
- 그래서 사용자는 카드 5장을 보고 나가면서 오늘 무엇을 얻었는지 모르고, 내일 와야 할 이유도 받지 못한다.
- 헤더 칩은 오늘 아직 안 했는지 이미 했는지 구분되지 않는다.
- 알림은 09/18시에 `○○, 이 단어 기억나시나요?`(단어 회상)를 보내며, 연속 학습 상태를 싣지 않는다.

## 제품 방향

- 오늘 학습이 기록되는 단위는 카드 1장이다. 세션 길이나 완료 여부와 무관하다.
- 연속 학습은 숫자가 아니라 "오늘 했음/아직" 상태로 보인다. 아직인 상태가 곧 오늘의 할 일이다.
- 완료 표시는 학습을 가리지 않는다. 카드 조작 영역 밖에서 나타나 스스로 사라진다.
- 알림은 단어가 아니라 오늘의 연속 학습 상태를 싣는다.

## 성공 기준

- 사용자는 하루 첫 rating 직후 연속 학습이 이어졌음을 카드 화면을 벗어나지 않고 확인한다.
- 사용자는 홈 진입 직후 헤더만 보고 오늘 학습을 했는지 아직인지 안다.
- 사용자는 헤더에서 이번 주 며칠을 채웠는지 안다.
- 로깅은 범위에 없다. 완료 여부는 수용 기준 QA로 판단하고, 배포 전후 D1 재방문율(현재 4/26)은 별도로 관찰한다.

## Scope

- A. 하루 첫 rating 시 오늘 학습 완료 표시
- B. 홈 헤더 칩의 오늘 상태(아직/완료)와 이번 주 7칸
- C. 연속 학습 상태를 싣는 알림 — 20:00 1차, 23:00 2차, 끊긴 뒤 3일. 기존 단어 회상 알림 대체
- D. 초반 마일스톤 — 미정

## Non-goal

- 세션 종료(`복습 완료 카드`) UX 변경
- 연속 학습 계산 규칙 변경 — 하루 첫 리뷰로 그날이 기록되는 현재 규칙을 그대로 쓴다
- 곡당 하루 새 카드 수 제한 (별도 intent)
- 한 번도 학습한 적 없는 유저를 첫 카드로 데려오는 알림 (별도 intent)
- freeze 지급·복구 규칙 변경
- 공유 카드, 리더보드, 친구 스트릭
- 프로필탭 학습 현황 화면 변경
- 온보딩과 목표 스트릭 (아래 "아이디어" 절에 보관)

## A. 첫 카드에서 오늘 학습 완료 알리기

**트리거**: 오늘 첫 rating이 기록된 직후. rating 종류(again/hard/good/easy)는 무관하다.

### A-1. 완료 표시 — 두 후보 중 하나만 택한다 (미확정)

두 후보는 배타적이다. 둘 다 넣으면 같은 순간에 같은 말을 두 번 하는 것이라 하나만 고른다. 디자인 단계에서 프로토타입으로 비교한 뒤 결정한다.

후보 1. 플로팅 배너

- 카드 스택 위쪽, 헤더와 카드 사이 영역에 나타나는 배너.
- 나타남 → 잠시 머무름 → 스스로 사라짐. 사용자가 닫을 필요가 없다.
- 헤더 칩은 같은 시점에 완료 상태로 바뀐다 (B).

후보 2. 카드에서 헤더로 날아가는 불꽃

- 첫 rating 순간 카드 위치에서 불꽃이 튀어 올라 헤더 칩에 도착하며 칩이 완료 상태로 바뀐다.
- 도착 시 칩 옆에 아래 표의 문구가 잠깐 떴다가 사라진다.
- 시선이 있는 카드에서 시작해 헤더에서 끝나므로, 칩이 연속 학습 표시기라는 것을 첫날에 가르친다.
- 몰입 상태라 헤더가 접혀 있으면 도착점이 없다. 이 경우의 표현은 이 후보를 택할 때 정한다.

공통:

- 카드의 탭·스와이프·rating 버튼 영역을 덮지 않는다.
- 학습 흐름을 멈추지 않는다. 사용자 조작을 요구하지 않는다.
- 탭 동작은 B-3의 칩 탭 동작과 같게 한다 (미결).

### A-2. 문구

N = 오늘 포함 연속 일수.

| 상황 | 문구 |
|---|---|
| 첫날 (N=1, 이전 기록 없음) | `🔥 연속 학습 시작!` |
| 이어감 (N≥2) | `🔥 연속 학습 N일째` |
| 끊긴 뒤 재시작 (N=1, 이전 기록 있음) | `🔥 다시 시작!` |
| 어제 freeze로 이어짐 (N≥2) | `🔥 연속 학습 N일째` (freeze 언급 없음) |

문구는 한 줄. 설명문·부연을 붙이지 않는다. "내일 올 이유"는 문구가 아니라 B의 아직 상태와 C의 알림이 맡는다.

### 주요 플로우

1. 사용자가 곡을 골라 카드 스택에 진입하고 첫 카드에 rating을 매긴다.
2. 시스템은 헤더 칩을 완료 상태로 바꾸며 `🔥 연속 학습 시작!`을 보여준다.
3. 사용자는 카드를 계속 넘기거나 그대로 나간다. 완료 표시는 스스로 사라진다.
4. 다음날 사용자가 다시 카드 하나에 rating을 매기면 `🔥 연속 학습 2일째`를 본다.

### 사이드케이스

- **오늘 이미 학습한 뒤 다시 들어온 경우**: 완료 표시를 다시 띄우지 않는다. 헤더 칩은 완료 상태다.
- **하루 경계(04:00)를 넘기며 학습 중인 경우**: 한 세션 안에서는 완료 표시를 한 번만 보인다. 다음 홈 진입 시 새 날짜 기준으로 갱신된다.

### 수용 기준

- [ ] 오늘 첫 rating 직후 완료 표시가 나타나고, 카드 조작 영역을 가리지 않는다.
- [ ] 완료 표시는 사용자 조작 없이 스스로 사라진다.
- [ ] 문구는 A-2 표와 일치한다.
- [ ] 같은 날 두 번째 이후 rating에는 완료 표시가 나타나지 않는다.

### 결정 경계

디자인이 정한다: 택한 후보의 크기, 위치, 등장·퇴장 애니메이션, 머무는 시간.

제품 확인이 필요하다: 후보 1/2의 선택, 문구, 오늘 학습이 기록되는 기준을 카드 1장이 아닌 값으로 바꾸는 것.

## B. 홈 헤더의 오늘 상태

홈 헤더의 연속 학습 칩을 "누적 숫자"에서 "오늘 아직/완료 표시기"로 바꾼다. 앱을 열자마자 보이는 첫 화면이 홈 카드이므로, 아직 상태의 칩이 곧 오늘의 할 일 안내다. 문구로 "카드 1장이면 켜져요"라고 쓰지 않는다 — A의 완료 표시가 칩이 바뀌는 순간을 눈앞에서 보여주므로, 한 번 겪으면 아직 상태의 뜻을 안다.

### B-1. 칩의 두 상태

| 상태 | 숫자 | 뜻 |
|---|---|---|
| 오늘 아직 | 어제까지 이어진 N (끊겼으면 0) | 오늘 한 장 넘기면 N+1 |
| 오늘 완료 | 오늘 포함 N | 오늘 몫 끝남 |

- `연속` 같은 보조 단어는 뺀다. 불꽃 + 숫자 + `일`.
- 아직 상태의 0일이 "끊김"이다. 별도 문구를 두지 않는다.
- 첫 rating 순간의 전환은 애니메이션으로 보인다. 홈 진입 시 이미 완료면 애니메이션 없이 그 상태로 그린다.

**두 상태를 시각적으로 어떻게 구분할지는 미확정.** 요구사항은 "헤더를 의식적으로 보지 않아도 오늘 아직 안 했다는 것이 눈에 들어올 것". 아이콘 틴트만 바꾸는 방식(색 있는 불꽃 ↔ 회색 불꽃)은 20px 아이콘의 색 차이라 이 요구를 못 채운다고 보고 제외한다. 디자인 후보:

- 칩 배경 채움: 아직은 외곽선만 있는 빈 필, 완료는 색으로 채워진 필. 틴트보다 크지만 "빈 필"이 아직으로 읽힐지 검증 필요.
- 불꽃 윤곽 ↔ 꽉 찬 불꽃. 위와 같은 의심이 있음.
- 헤더 전체의 배경 톤 변화: 완료 후 앱바가 따뜻한 톤이 됨. 면적이 커서 잘 보이지만 헤더 밖 UI와 충돌할 수 있음.
- 아직 상태의 칩에 짧은 라벨(예: `오늘 아직`)을 붙이고 완료 후 지움. 가장 확실하지만 문구 의존.

기각: 표시기를 카드에 붙이는 안 — "오늘 첫 카드"에만 붙일 수 있어 두 번째 진입부터 사라지고, 헤더 상태의 대체가 되지 못한다.

어느 후보든 7칸의 오늘 칸이 비어 있는 것이 두 번째 단서로 함께 간다.

### B-2. 이번 주 7칸

- 칩 옆 또는 아래에 월~일 7칸을 둔다.
- 칸 상태: 학습함 / freeze / 오늘(아직이면 빈 칸 강조, 완료면 학습함) / 없음 / 아직 안 온 날.
- 요일 글자는 넣지 않거나 한 글자만. 칸은 눈금이지 캘린더가 아니다.
- 프로필탭 히트맵과 역할이 겹치지 않도록 이번 주 7칸만.

### B-3. 칩 탭 동작 (미결)

- 칩을 탭했을 때 무엇이 일어날지는 정하지 않았다. 후보: 프로필탭으로 이동 (연속 학습 상세는 이미 거기 있다) / 탭 없음(표시기로만 둔다).
- 별도 바텀시트는 만들지 않는다. 내용이 프로필탭과 겹친다.

### B-4. 몰입 상태

- 헤더가 접힌(몰입) 상태에서는 칩도 같이 접힌다. 몰입 중에도 보여주려고 별도 UI를 만들지 않는다. 카드를 넘기기 시작한 유저는 이미 완료 직전이다.

### 주요 플로우

1. 사용자가 앱을 열어 홈에 진입한다.
2. 헤더에 아직 상태의 칩 `3일`과 이번 주 7칸(월·화·수 채워짐, 목요일 오늘 빈 칸 강조)이 보인다.
3. 사용자가 첫 카드에 rating을 매긴다.
4. 칩이 완료 상태 `4일`로 바뀌고 목요일 칸이 채워진다. 동시에 A의 완료 표시가 나타난다.

### 사이드케이스

- **끊긴 상태로 진입**: 아직 상태의 `0일`과 7칸. 끊김을 설명하는 문구는 없다. 첫 카드를 넘기면 완료 `1일`, A는 `🔥 다시 시작!`.
- **어제가 freeze로 채워짐**: 아직 상태에 끊기지 않은 숫자 N, 어제 칸은 freeze 표시. freeze가 어제를 막았음이 7칸에서 보인다.

### 수용 기준

- [ ] 오늘 아직이면 칩은 아직 상태로 보이고, 숫자는 어제까지의 연속 일수다.
- [ ] 오늘 첫 rating 직후 칩이 완료 상태로 바뀌고 숫자가 1 늘어난다.
- [ ] 홈 재진입 시 오늘 이미 학습했으면 애니메이션 없이 완료 상태로 보인다.
- [ ] 헤더에 이번 주 월~일 7칸이 보이고, 학습/freeze/오늘/없음이 구분된다.
- [ ] 끊긴 상태는 아직 상태의 `0일`로 보이며 설명 문구가 없다.
- [ ] 몰입 상태에서는 칩이 헤더와 함께 접힌다.

### 결정 경계

디자인이 정한다: 택한 구분 방식 안에서의 색·아이콘·수치, 전환 애니메이션, 7칸의 크기·간격·위치(칩 안 또는 아래 줄, 앱바 높이는 넘겨도 된다).

제품 확인이 필요하다: 아직/완료 구분 방식의 선택, 칩 탭 동작, 칩에 문구를 추가하는 것(라벨 후보 제외), 몰입 상태용 별도 UI, 아직 상태를 시간대에 따라 다르게 보이게 하는 것(예: 저녁 이후 "위험" 표시).

## C. 연속 학습을 싣는 알림

앱을 열지 않은 유저에게 연속 학습 상태가 닿는 유일한 채널이다. 알림의 프레임을 "이 단어 기억나세요?"(단어 회상)에서 "오늘 연속 학습이 아직이에요"(오늘 상태)로 바꾼다. 알림을 탭하면 홈 첫 카드로 떨어지고, 한 장 넘기면 A의 완료 표시가 뜬다.

현재: 09:00 / 18:00에 리뷰한 카드가 due인 유저에게 단어 회상 알림. 9/18에 14명에게 두 번 보냈고 그날 DAU는 3명. 토큰이 있는 9월 가입자 10명은 조건을 못 채워 알림을 한 번도 못 받았다.

### C-1. 발송 시각

전원 같은 시각. 하루 최대 2건. 기존 09/18시 단어 회상 알림은 폐기한다.

| 슬롯 | 시각 (KST) | 뜻 |
|---|---|---|
| 1차 | 20:00 | 저녁, 오늘 아직 안 했으면 알려줌 |
| 2차 | 23:00 | 잠들기 전 마지막 한 번 |

- 두 시각은 행동 데이터에서 나온 값이 아니다. "저녁 여가 시간"과 "잠들기 전"을 3시간 간격으로 잡은 추측이며, 탭 후 학습으로 이어진 비율을 보고 조정한다.
- 하루 경계가 04:00이라 2차 뒤에도 시간이 남지만, 문구에 남은 시간이나 리셋 시각을 넣지 않는다.

### C-2. 대상과 문구

공통 조건: 알림이 켜져 있고, 한 번이라도 학습한 적 있고, 발송 시점에 오늘 아직 학습하지 않았다. 오늘 학습했으면 그날은 어떤 연속 학습 알림도 보내지 않는다.

N = 어제까지 이어진 연속 일수 (B-1의 아직 상태 숫자).

| 슬롯 | 조건 | 제목 | 본문 |
|---|---|---|---|
| 1차 20:00 | N = 1 (어제 시작) | `어제 시작한 연속 학습, 오늘도 이어가요` | `카드 한 장이면 2일째예요` |
| 1차 20:00 | N ≥ 2 | `🔥 연속 학습 N일째, 오늘은 아직이에요` | `카드 한 장이면 N+1일째예요` |
| 2차 23:00 | N = 1 | `자기 전에 카드 한 장 어때요?` | `연속 학습 2일째가 돼요` |
| 2차 23:00 | N ≥ 2 | `N일 연속 학습, 오늘 놓치면 끊겨요` | `카드 한 장이면 지킬 수 있어요` |
| 1차 20:00 | 끊긴 다음날 (N = 0) | `연속 학습이 어제 끊겼어요` | `오늘 한 장 넘기면 다시 1일째` |
| 1차 20:00 | 끊긴 뒤 2~3일째 (N = 0) | `연속 학습 다시 시작해볼까요?` | `카드 한 장이면 돼요` |
| 2차 23:00 | N = 0 | 보내지 않음 | |

- 제목은 연속 학습 상태, 본문은 항상 "카드 한 장"이라는 행동 하나. 단어를 싣지 않는다.
- N = 1에도 2차를 보내는 이유: 첫날 → 둘째날이 가장 큰 이탈 지점(D1 15%)이라 이 하루만큼은 두 번 말한다.
- 끊긴 유저에게는 끊긴 다음날부터 3일까지만 1차를 보내고 그 뒤 멈춘다. 다시 학습하면 처음부터 다시 센다.
- 한 번도 학습한 적 없는 유저(현재 31명)는 대상이 아니다. 지킬 연속 학습이 없다. 첫 카드로 데려오는 알림은 별도 intent.
- 곡 분석 완료 알림은 이 규칙과 무관하게 그대로 간다.

### C-3. 탭 후

- 홈 첫 카드로 간다. 홈은 평소대로 due 많은 곡의 첫 카드를 보여주고, 헤더는 아직 상태(B). 한 장 넘기면 A의 완료 표시.
- 알림에서 온 것을 표시하는 별도 화면·배너는 없다.

### 주요 플로우

1. 사용자가 어제까지 3일 연속이고 오늘 20:00까지 앱을 열지 않았다.
2. 20:00에 `🔥 연속 학습 3일째, 오늘은 아직이에요 / 카드 한 장이면 4일째예요`를 받는다.
3. 사용자가 알림을 탭해 홈 첫 카드로 들어와 한 장을 넘긴다.
4. A의 완료 표시가 뜨고 헤더가 `4일`로 바뀐다. 23:00 2차는 오지 않는다.

### 사이드케이스

- **20:00 전에 이미 학습**: 그날 알림 없음.
- **1차를 무시함 (N ≥ 2)**: 23:00에 `N일 연속 학습, 오늘 놓치면 끊겨요`. 새벽 02:00에 한 장 넘겨도 오늘(04:00 전)로 기록된다.
- **어제 처음 시작 (N = 1)**: 20:00과 23:00 두 번 온다.
- **끊김**: 다음날부터 3일간 20:00만. 나흘째부터 멈춘다. 다시 학습하면 N = 1 규칙으로 돌아간다.

### 수용 기준

- [ ] 오늘 학습하지 않은 유저에게만 연속 학습 알림이 간다.
- [ ] 1차 20:00, 2차 23:00, 전원 같은 시각이다.
- [ ] 2차는 N ≥ 1일 때만 가고, 끊긴 유저에게는 가지 않는다.
- [ ] 문구는 C-2 표와 일치하고, 남은 시간이나 리셋 시각을 언급하지 않는다.
- [ ] 끊긴 유저에게는 끊긴 다음날부터 3일만 간다.
- [ ] 한 번도 학습한 적 없는 유저에게는 가지 않는다.
- [ ] 알림을 탭하면 홈 첫 카드가 열린다.
- [ ] 기존 09/18시 단어 회상 알림은 더 이상 가지 않는다.

### 결정 경계

제품 확인이 필요하다: 문구, 20:00 / 23:00 / 끊긴 뒤 3일 값, 하루 2건을 넘기는 것, 발송 시각을 유저별로 다르게 하는 것, 한 번도 학습하지 않은 유저를 대상에 넣는 것, 단어 회상 알림을 남겨두는 것.

## D. 초반 마일스톤 (미정)

연속 학습이 특정 일수(예: 3, 7, 14, 30일)에 닿는 날, 첫 카드를 넘기면 "N일 됐다"를 크게 한 번 보여주는 것. 매일 1씩 오르기만 하는 숫자에 도착점을 만들어 "6일째, 내일이면 7일"인 사람이 오늘 끊기 아깝게 하려는 의도다.

근거는 약하다. 듀오링고의 7/14/30/50/100을 따라온 것이고, 우리 데이터로 효과를 보인 게 아니다. D1이 15%인 지금은 3일 도착점을 볼 유저 자체가 소수라 A·B·C보다 우선순위가 낮다.

두 갈래가 있다. 실제 디자인을 해본 뒤 정한다.

- 최소판: 축하 화면 없이, 마일스톤 전날 20:00 알림 문구만 바꾼다 (`오늘 한 장이면 연속 학습 7일이에요 / 카드 한 장으로 채워요`).
- 전체판: 마일스톤 날 첫 rating 직후 전체 화면 축하 (큰 숫자, `N일 연속 학습`, 버튼 하나 `계속하기`). 그날은 A의 완료 표시 대신 이 화면이 뜬다. 학습 흐름을 끊는 유일한 지점.

## 아이디어 (보류)

### 온보딩 목표 스트릭

가입 직후 한 화면에서 목표 연속 일수(3/7/14/30일)를 고르게 하고, 이후 완료 표시·헤더·알림이 모두 `N/G일`로 목표 대비 진행을 보여주는 안. "내일 올 이유"를 앱 문구가 아니라 유저 자신의 약속으로 만드는 게 의도. 달성 시 전체 화면 축하 후 다음 목표 선택.

보류 이유: 첫 카드까지 못 가는 유저가 절반이라 곡 탐색 전 단계를 늘리는 게 부담. A·B·C로 D1이 움직이는지 본 뒤 재검토.
