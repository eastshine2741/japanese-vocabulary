# Product Intent: Streak Commitment

연속 학습을 "세션을 끝낸 보상"이 아니라 "첫 카드 한 장의 즉시 결과"로 만들고, 홈에 들어온 순간부터 오늘 학습을 했는지 아직인지가 보이게 한다.

용어: 사용자에게 보이는 이름은 **연속 학습**. "스트릭"은 이 문서 안의 내부 용어다. 문구는 사람이 말로 하는 표현만 쓴다.

## 데이터 근거 (prod, 2026-09-18)

- 가입 59명 → 복습 시작 28명 (47%) → 이틀째 복습 4명 (15%) → 4일 이상 2명.
- 단어는 곡을 열 때 30~60장 일괄 저장되고 첫 복습은 그 직후 시작된다. 유저는 "복습하러" 온 게 아니라 곡을 열었더니 카드가 나온 것.
- 1일만 학습한 유저 18명의 첫 세션: 중앙값 카드 5장, 1분 안팎. 5명은 1장만 보고 이탈.
- 홈 스택의 `복습 완료 카드`는 곡의 due를 다 비워야 나오는데 새 곡은 due가 30~60장이라 도달한 유저는 4명뿐.
- 유저별 학습 시각은 일정하지 않다. 첫 세션 시각의 쏠림은 릴스 업로드 시각을 따른 유입 시각이지 습관이 아니다.
- 하루의 경계는 자정이 아니라 KST 04:00이다. 새벽 학습은 전날로 친다.

결론: 세션 종료 화면에 연속 학습을 걸면 대부분의 유저가 보지 못한다. 하루 첫 카드에 rating을 매기는 시점이 모든 학습 유저가 통과하는 유일한 지점이다.

## 사용자 목표

- 사용자는 카드 한 장만 넘겨도 오늘 연속 학습이 이어졌음을 그 자리에서 안다.
- 사용자는 홈에 들어오자마자 오늘 학습을 했는지 아직인지 안다.
- 사용자는 학습 흐름을 멈추지 않고 위 두 가지를 확인한다.

## 현재 문제

- 연속 학습은 하루 첫 리뷰 시 이미 쌓이지만, 사용자는 홈 헤더의 정적 숫자(`🔥 N일 연속`) 외에 그 사실을 알 방법이 없다.
- 그래서 사용자는 카드 5장을 보고 나가면서 오늘 무엇을 얻었는지 모르고, 내일 와야 할 이유도 받지 못한다.
- 헤더 칩만으로는 오늘 아직 안 했는지 이미 했는지 알 수 없다.
- 알림은 09/18시에 `○○, 이 단어 기억나시나요?`(단어 회상)를 보내며, 연속 학습 상태를 싣지 않는다.

## 제품 방향

- 오늘 학습이 기록되는 단위는 카드 1장이다. 세션 길이나 완료 여부와 무관하다.
- 홈 헤더는 오늘 아직인지 말풍선으로 말해 준다. 그 말풍선이 곧 오늘의 할 일이다.
- 완료 표시는 학습을 가리지 않는다. 카드 조작 영역 밖에서 나타나 스스로 사라진다.
- 알림은 단어가 아니라 오늘의 연속 학습 상태를 싣는다.

## 성공 기준

- 사용자는 하루 첫 rating 직후 연속 학습이 이어졌음을 카드 화면을 벗어나지 않고 확인한다.
- 사용자는 홈 진입 직후 헤더만 보고 오늘 학습을 했는지 아직인지 안다.
- 로깅은 범위에 없다. 완료 여부는 수용 기준 QA로 판단하고, 배포 전후 D1 재방문율(현재 4/26)은 별도로 관찰한다.

## Scope

- A. 하루 첫 rating 시 오늘 학습 완료 표시
- B. 홈 헤더 칩 아래 "오늘 아직" 말풍선 넛지
- C. 연속 학습 상태를 싣는 알림 — 20:00 1차, 23:00 2차, 끊긴 뒤 3일. 기존 단어 회상 알림 대체

## Non-goal

- 세션 종료(`복습 완료 카드`) UX 변경
- 연속 학습 계산 규칙 변경 — 하루 첫 리뷰로 그날이 기록되는 현재 규칙을 그대로 쓴다
- 곡당 하루 새 카드 수 제한 (별도 intent)
- 한 번도 학습한 적 없는 유저를 첫 카드로 데려오는 알림 (별도 intent)
- freeze 지급·복구 규칙 변경
- 공유 카드, 리더보드, 친구 스트릭
- 프로필탭 학습 현황 화면 변경
- 헤더에 주간 캘린더·7칸 눈금을 두는 것 — 주간 기록은 프로필탭 히트맵이 맡는다
- 온보딩과 목표 스트릭 (아래 "아이디어" 절에 보관)

## A. 첫 카드에서 오늘 학습 완료 알리기

**트리거**: 오늘 첫 rating이 기록된 직후. rating 종류(again/hard/good/easy)는 무관하다.

### A-1. 완료 표시 — 플로팅 배너

- 카드 스택 위쪽, 몰입 크롬 진행바 아래 영역에 나타나는 배너. 양옆 16 여백.
- 위에서 8px 내려오며 페이드 인 → 잠시 머무름 → 스스로 페이드 아웃. 사용자가 닫을 필요가 없고 탭 동작도 없다.
- 카드의 탭·스와이프·rating 버튼 영역을 덮지 않는다. 학습 흐름을 멈추지 않는다.
- 헤더의 말풍선 넛지는 다음에 헤더가 펼쳐질 때 사라져 있다 (B).

기각: 카드에서 헤더 칩으로 불꽃이 날아가는 안 — 홈에서 rating은 항상 몰입 상태(헤더 접힘)에서 일어나 도착점이 없다.

### A-2. 문구

배너는 두 줄이다. 윗줄(작은 글자)은 연속 학습 상태, 아랫줄(큰 글자)은 그 상태에 붙이는 한마디. N = 오늘 포함 연속 일수.

| 상황 | 윗줄 | 아랫줄 |
|---|---|---|
| 첫날 (N=1, 이전 기록 없음) | `연속 학습 시작` | `오늘부터 함께 힘내요!` |
| 이어감 (N≥2) | `연속 학습 N일째` | `N일째 이어가고 있어요!` |
| 끊긴 뒤 재시작 (N=1, 이전 기록 있음) | `연속 학습 다시 시작` | `돌아오신 걸 환영해요!` |
| 어제 freeze로 이어짐 (N≥2) | 이어감과 동일 (freeze 언급 없음) | |

설명문·부연을 붙이지 않는다. "내일 올 이유"는 문구가 아니라 B의 말풍선과 C의 알림이 맡는다.

### 주요 플로우

1. 사용자가 곡을 골라 카드 스택에 진입하고 첫 카드에 rating을 매긴다.
2. 시스템은 배너 `연속 학습 시작 / 오늘부터 함께 힘내요!`를 보여준다.
3. 사용자는 카드를 계속 넘기거나 그대로 나간다. 완료 표시는 스스로 사라진다.
4. 다음날 사용자가 다시 카드 하나에 rating을 매기면 `연속 학습 2일째 / 2일째 이어가고 있어요!`를 본다.

### 사이드케이스

- **오늘 이미 학습한 뒤 다시 들어온 경우**: 완료 표시를 다시 띄우지 않는다. 헤더에 말풍선도 없다.
- **하루 경계(04:00)를 넘기며 학습 중인 경우**: 한 세션 안에서는 완료 표시를 한 번만 보인다. 다음 홈 진입 시 새 날짜 기준으로 갱신된다.

### 수용 기준

- [ ] 오늘 첫 rating 직후 완료 표시가 나타나고, 카드 조작 영역을 가리지 않는다.
- [ ] 완료 표시는 사용자 조작 없이 스스로 사라진다.
- [ ] 문구는 A-2 표와 일치한다.
- [ ] 같은 날 두 번째 이후 rating에는 완료 표시가 나타나지 않는다.

### 결정 경계

디자인이 정한다: 배너의 크기, 위치, 등장·퇴장 애니메이션, 머무는 시간.

제품 확인이 필요하다: 문구, 배너에 탭 동작을 넣는 것, 오늘 학습이 기록되는 기준을 카드 1장이 아닌 값으로 바꾸는 것.

## B. 홈 헤더의 오늘 상태

홈 헤더의 연속 학습 칩(`🔥 N일 연속`)은 지금 디자인 그대로 두고, 오늘 아직 학습하지 않았으면 칩 아래에 말풍선 넛지를 붙인다. B에 의한 화면 차이는 말풍선 유무뿐이다. 앱을 열자마자 보이는 첫 화면이 홈 카드이므로, 이 말풍선이 곧 오늘의 할 일 안내다. 칩 자체는 상태에 따라 모양을 바꾸지 않는다 — 칩 스타일 차이(빈 필/채운 필, 회색 불꽃 등)로 아직/완료를 구분하는 방식은 뜻이 읽히지 않아 기각했다.

### B-1. 칩과 말풍선

칩: 기존 `🔥 N일 연속` 그대로. 상태에 따라 모양·색·문구를 바꾸지 않는다.

| 상황 | 숫자 | 말풍선 |
|---|---|---|
| 오늘 아직 | 어제까지 이어진 N (끊겼으면 0) | `아직 오늘의 학습을 하지 않았어요` |
| 오늘 완료 | 오늘 포함 N | 없음 |

- 말풍선은 칩 바로 아래, 꼬리가 칩을 가리킨다. 앱바 아래 영역 위에 떠 있다.
- 말풍선은 한 줄. 남은 시간, 카드 수, 끊김 설명을 넣지 않는다.
- 끊긴 상태는 `0일` + 같은 말풍선이다. 끊김을 설명하는 별도 문구를 두지 않는다.
- 오늘 첫 rating 뒤 몰입이 풀려 헤더가 다시 펼쳐질 때 말풍선이 사라지고 숫자가 +1 된다. 홈 진입 시 이미 완료면 말풍선 없이 숫자만 그린다.
- 말풍선은 사용자가 닫지 않는다. 오늘 한 장 넘기는 것만이 닫는 방법이다.

칩은 오늘 상태와 숫자만 담는다. 이번 주 며칠을 채웠는지 같은 주간 정보는 넣지 않는다 — 주간 기록은 프로필탭 히트맵이 이미 맡고 있다.

기각: 표시기를 카드에 붙이는 안 — "오늘 첫 카드"에만 붙일 수 있어 두 번째 진입부터 사라지고, 헤더 상태의 대체가 되지 못한다.

### B-2. 칩 탭 동작 (미결)

- 칩을 탭했을 때 무엇이 일어날지는 정하지 않았다. 후보: 프로필탭으로 이동 (연속 학습 상세는 이미 거기 있다) / 탭 없음(표시기로만 둔다).
- 별도 바텀시트는 만들지 않는다. 내용이 프로필탭과 겹친다.

### B-3. 몰입 상태

- 헤더가 접힌(몰입) 상태에서는 칩과 말풍선도 같이 접힌다. 몰입 중에도 보여주려고 별도 UI를 만들지 않는다. 카드를 넘기기 시작한 유저는 이미 완료 직전이다.

### 주요 플로우

1. 사용자가 앱을 열어 홈에 진입한다.
2. 헤더에 칩 `3일`과 그 아래 말풍선 `아직 오늘의 학습을 하지 않았어요`가 보인다.
3. 사용자가 첫 카드에 rating을 매긴다. A의 완료 표시가 나타난다.
4. 몰입이 풀려 헤더가 펼쳐지면 말풍선은 없고 칩은 `4일`이다.

### 사이드케이스

- **끊긴 상태로 진입**: `0일` + 말풍선. 끊김을 설명하는 문구는 없다. 첫 카드를 넘기면 `1일`, A는 `연속 학습 다시 시작 / 돌아오신 걸 환영해요!`.
- **어제가 freeze로 채워짐**: 끊기지 않은 숫자 N + 말풍선. 헤더에서 freeze를 따로 표시하지 않는다.

### 수용 기준

- [ ] 오늘 아직이면 칩 아래 말풍선이 보이고, 숫자는 어제까지의 연속 일수다.
- [ ] 오늘 첫 rating 후 헤더가 다시 펼쳐지면 말풍선이 없고 숫자가 1 늘어나 있다.
- [ ] 홈 진입 시 오늘 이미 학습했으면 말풍선 없이 숫자만 보인다.
- [ ] 끊긴 상태는 `0일` + 말풍선으로 보이며 설명 문구가 없다.
- [ ] 말풍선 문구는 B-1 표와 일치한다.
- [ ] 몰입 상태에서는 칩과 말풍선이 헤더와 함께 접힌다.

### 결정 경계

디자인이 정한다: 말풍선의 색·크기·위치·꼬리, 등장·퇴장 애니메이션.

제품 확인이 필요하다: 말풍선 문구, 칩 탭 동작, 칩 스타일을 상태에 따라 바꾸는 것, 칩에 주간 정보를 넣는 것, 몰입 상태용 별도 UI, 아직 상태를 시간대에 따라 다르게 보이게 하는 것(예: 저녁 이후 "위험" 표시).

## C. 연속 학습을 싣는 알림

앱을 열지 않은 유저에게 연속 학습 상태가 닿는 유일한 채널이다. 알림의 프레임을 "이 단어 기억나세요?"(단어 회상)에서 "오늘 연속 학습이 아직이에요"(오늘 상태)로 바꾼다. 알림을 탭하면 홈 첫 카드로 떨어지고, 한 장 넘기면 A의 완료 표시가 뜬다.

현재: 09:00 / 18:00에 리뷰한 카드가 due인 유저에게 단어 회상 알림. 9/18에 14명에게 두 번 보냈고 그날 DAU는 3명. 토큰이 있는 9월 가입자 10명은 조건을 못 채워 알림을 한 번도 못 받았다.

### C-1. 발송 시각

전원 같은 시각. 하루 최대 2건. 기존 09/18시 단어 회상 알림은 폐기한다.

| 슬롯 | 시각 (KST) | 뜻 |
|---|---|---|
| 1차 | 20:00 | 저녁, 오늘 아직 안 했으면 알려줌 |
| 2차 | 23:00 | 잠들기 전 마지막 한 번 |

- 두 시각은 행동 데이터에서 나온 값이 아니다. "저녁 여가 시간"과 "잠들기 전"을 3시간 간격으로 잡은 추측이며, 탭 후 학습으로 이어진 비율을 보고 조정한다.
- 하루 경계가 04:00이라 2차 뒤에도 시간이 남지만, 문구에 남은 시간이나 리셋 시각을 넣지 않는다.

### C-2. 대상과 문구

공통 조건: 알림이 켜져 있고, 한 번이라도 학습한 적 있고, 발송 시점에 오늘 아직 학습하지 않았다. 오늘 학습했으면 그날은 어떤 연속 학습 알림도 보내지 않는다.

N = 어제까지 이어진 연속 일수 (B-1의 오늘 아직 숫자).

| 슬롯 | 조건 | 제목 | 본문 |
|---|---|---|---|
| 1차 20:00 | N = 1 (어제 시작) | `어제의 첫 걸음을 이어가볼까요?` | `카드 한 장만 넘기면 연속 학습 2일째예요!` |
| 1차 20:00 | N ≥ 2 | `🔥 N일 연속 학습 중! 오늘은 아직이에요` | `카드 한 장만 넘기면 N+1일째로 이어져요` |
| 2차 23:00 | N = 1 | `⚠️ 어제 시작한 연속 학습이 끊기기 직전` | `자기 전에 카드 한 장만 넘겨주세요` |
| 2차 23:00 | N ≥ 2 | `⚠️ N일 연속이 끊기기 직전` | `지금 카드 한 장만 넘겨주세요` |
| 1차 20:00 | 끊긴 다음날 (N = 0) | `오늘 카드 한 장으로 다시 시작해요` | `어제 끊긴 연속 학습을 오늘 1일째부터 다시 쌓아요` |
| 1차 20:00 | 끊긴 뒤 2~3일째 (N = 0) | `오늘 다시 시작해볼까요?` | `카드 한 장만 넘기면 연속 학습 1일째예요` |
| 2차 23:00 | N = 0 | 보내지 않음 | |

- 제목은 이목을 끄는 한 줄, 본문은 "카드 한 장만 넘기면"이라는 행동 하나. 단어를 싣지 않는다.
- 1차 20:00은 리마인드 수준으로 담백하게, 2차 23:00은 "끊기기 직전"으로 위기감을 올린다. N = 1의 2차는 어제 막 시작한 아쉬움을 싣는다.
- "마지막 기회" 같은 Duolingo식 표현은 쓰지 않는다. 문구에 쉼표를 쓰지 않는다.
- 끊긴 유저에게는 위협할 것이 없으므로 제목에 행동("오늘 카드 한 장으로 다시 시작")을 바로 쓴다.
- N = 1에도 2차를 보내는 이유: 첫날 → 둘째날이 가장 큰 이탈 지점(D1 15%)이라 이 하루만큼은 두 번 말한다.
- 끊긴 유저에게는 끊긴 다음날부터 3일까지만 1차를 보내고 그 뒤 멈춘다. 다시 학습하면 처음부터 다시 센다.
- 한 번도 학습한 적 없는 유저(현재 31명)는 대상이 아니다. 지킬 연속 학습이 없다. 첫 카드로 데려오는 알림은 별도 intent.
- 곡 분석 완료 알림은 이 규칙과 무관하게 그대로 간다.

### C-3. 탭 후

- 홈 첫 카드로 간다. 홈은 평소대로 due 많은 곡의 첫 카드를 보여주고, 헤더에는 말풍선(B). 한 장 넘기면 A의 완료 표시.
- 알림에서 온 것을 표시하는 별도 화면·배너는 없다.

### 주요 플로우

1. 사용자가 어제까지 3일 연속이고 오늘 20:00까지 앱을 열지 않았다.
2. 20:00에 `🔥 3일 연속 학습 중! 오늘은 아직이에요 / 카드 한 장만 넘기면 4일째로 이어져요`를 받는다.
3. 사용자가 알림을 탭해 홈 첫 카드로 들어와 한 장을 넘긴다.
4. A의 완료 표시가 뜨고 헤더는 말풍선 없이 `4일`이 된다. 23:00 2차는 오지 않는다.

### 사이드케이스

- **20:00 전에 이미 학습**: 그날 알림 없음.
- **1차를 무시함 (N ≥ 2)**: 23:00에 `⚠️ N일 연속이 끊기기 직전 / 지금 카드 한 장만 넘겨주세요`. 새벽 02:00에 한 장 넘겨도 오늘(04:00 전)로 기록된다.
- **어제 처음 시작 (N = 1)**: 20:00과 23:00 두 번 온다.
- **끊김**: 다음날부터 3일간 20:00만. 나흘째부터 멈춘다. 다시 학습하면 N = 1 규칙으로 돌아간다.

### 수용 기준

- [ ] 오늘 학습하지 않은 유저에게만 연속 학습 알림이 간다.
- [ ] 1차 20:00, 2차 23:00, 전원 같은 시각이다.
- [ ] 2차는 N ≥ 1일 때만 가고, 끊긴 유저에게는 가지 않는다.
- [ ] 문구는 C-2 표와 일치하고, 남은 시간이나 리셋 시각을 언급하지 않는다.
- [ ] 끊긴 유저에게는 끊긴 다음날부터 3일만 간다.
- [ ] 한 번도 학습한 적 없는 유저에게는 가지 않는다.
- [ ] 알림을 탭하면 홈 첫 카드가 열린다.
- [ ] 기존 09/18시 단어 회상 알림은 더 이상 가지 않는다.

### 결정 경계

제품 확인이 필요하다: 문구, 20:00 / 23:00 / 끊긴 뒤 3일 값, 하루 2건을 넘기는 것, 발송 시각을 유저별로 다르게 하는 것, 한 번도 학습하지 않은 유저를 대상에 넣는 것, 단어 회상 알림을 남겨두는 것.
