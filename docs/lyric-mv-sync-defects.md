# 가사 MV 싱크로 드러난 곡 데이터 결함

로컬 실행기(`lyric-sync-agent/`)가 prod 곡을 처리하며 드러난 결함 기록. 실행기는 MV 오디오를 실제로 듣기 때문에
MV 오연결·가사 오연결이 FAILED 나 LOW 로 드러난다. 곡을 고치면(MV·가사 교체) 새 (가사, MV) 조합이 자동으로 다시
대기열에 들어간다. 고친 행은 지우지 말고 `처리` 칸을 채운다.

- `sync` 는 `lyric_mv_sync.id`, `song` 은 `songs.id`. 어드민 Lyric MV Sync 에서 `sync` 로 열어 들어 볼 수 있다.
- `찾은 줄` 은 실행기가 MV 에서 찾은 가사 줄 / 전체 줄.
- 실행기 쪽 한계(합성음 보컬 등)로 LOW 인 곡은 데이터 결함이 아니라 맨 아래에 따로 둔다.

## 데이터 결함 아님 (실행기 한계)

합성음·가공 보컬이 빠른 곡은 Whisper 가 거의 못 들어 LOW 다. LOW 는 앱에 내리지 않으므로 둘 곳만 기록한다.

いちにのさんで(71), ダメダメ(82), プシ(91), 風呂入るプロファイル(275), ループザルーム(285), 点.mp4(328), ことばのおばけがまどからみている(379), ドレスコード(419) — 괄호는 `sync`.
